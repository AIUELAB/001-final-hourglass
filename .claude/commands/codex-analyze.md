# AI協調分析 Skill

## 概要
Codex MCPと連携し、複数のAI視点から統合分析を行います。

## 使用方法

```bash
/codex-analyze              # 標準分析
/codex-analyze deep         # 詳細分析
/codex-analyze <topic>      # 特定トピック分析
```

## 分析視点

1. **アーキテクチャ視点**: システム構造、設計パターン
2. **品質視点**: コード品質、テストカバレッジ
3. **セキュリティ視点**: 脆弱性、ベストプラクティス
4. **パフォーマンス視点**: 効率性、最適化機会
