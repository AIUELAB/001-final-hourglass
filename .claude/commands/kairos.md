# KAIROS Skill

## 概要
プロジェクトの状態を分析し、改善機会と最適な実行タイミングを検出します。

## 使用方法

```bash
/kairos              # 機会検出
/kairos scan         # 全体スキャン
/kairos priority     # 優先度付き提案
```

## 検出対象

1. **技術的機会**: リファクタリング、最適化
2. **品質改善機会**: テスト追加、ドキュメント整備
3. **アーキテクチャ機会**: 設計改善、パターン適用
4. **運用改善機会**: 自動化、効率化

## 優先度評価基準

| レベル | 条件 | アクション |
|--------|------|-----------|
| 🔴 緊急 | セキュリティ、バグ | 即時対応 |
| 🟡 重要 | 品質、パフォーマンス | 今週中 |
| 🟢 推奨 | 改善、最適化 | 計画的に |

## 出力形式

```
⏱️ KAIROS機会検出レポート
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🔴 緊急 (今すぐ):
  - [機会1]

🟡 重要 (今週中):
  - [機会2]

🟢 推奨 (計画的):
  - [機会3]

📅 推奨実行タイミング:
  - [タイミング提案]
```
