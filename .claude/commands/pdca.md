# PDCAガーディアン Skill

## 概要
プロジェクトの品質状態を分析し、PDCA改善提案を行います。

## 使用方法

```bash
/pdca              # 全体分析
/pdca check        # クイックチェック
/pdca report       # 詳細レポート生成
```

## 分析対象

1. **Plan**: 計画の妥当性、目標設定
2. **Do**: 実装状況、進捗
3. **Check**: テスト結果、品質メトリクス
4. **Act**: 改善アクション、次のサイクル

## 実行内容

以下のファイルを読み込んで分析:
- `.session/STATUS.md` - 現在の進捗状態
- `rule_health_report.json` - ルール健全性レポート
- `tests/` - テスト結果

## 出力形式

```
📊 PDCAガーディアン分析レポート
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🎯 Plan（計画）: [状態]
📝 Do（実行）: [状態]
✅ Check（評価）: [状態]
🔄 Act（改善）: [提案]

💡 推奨アクション:
1. [アクション1]
2. [アクション2]
```

---

分析を開始します。`.session/STATUS.md`と関連ファイルを読み込んで、PDCA観点での品質評価を行ってください。
