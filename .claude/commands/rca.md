# RCA-Kaizen Skill

## 概要
問題の根本原因を分析し、継続的改善（Kaizen）を提案します。

## 使用方法

```bash
/rca                    # 最近のエラー分析
/rca <error_message>    # 特定エラー分析
/rca history            # 改善履歴確認
```

## RCA（Root Cause Analysis）プロセス

```
問題発生
    ↓
1. 現象の記録
    ↓
2. 5 Whys分析
    ↓
3. 根本原因特定
    ↓
4. 対策立案
    ↓
5. 効果検証
```

## Kaizen（改善）サイクル

1. **問題認識**: 何が起きているか
2. **原因分析**: なぜ起きたか（5 Whys）
3. **対策実施**: どう解決するか
4. **標準化**: 再発防止策
5. **水平展開**: 類似箇所への適用
