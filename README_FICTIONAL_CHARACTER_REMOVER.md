# Fictional Character Remover - Usage Guide

## 🚀 Quick Start

```bash
python remove_fictional_characters.py
```

The script will:
1. Automatically find the latest `ultra_think_*.csv` file
2. Create a safety backup
3. Remove fictional characters and empty entries
4. Generate detailed reports
5. Save the cleaned database

## 📁 Output Files

- **Cleaned Database:** `ultra_think_FICTIONAL_REMOVED_YYYYMMDD_HHMMSS.csv`
- **Backup:** `backup_before_fictional_removal_YYYYMMDD_HHMMSS.csv`
- **Removal Log:** `removed_fictional_characters_YYYYMMDD_HHMMSS.csv`
- **Statistics:** `fictional_removal_stats_YYYYMMDD_HHMMSS.json`
- **Report:** `FICTIONAL_REMOVAL_REPORT_YYYYMMDD_HHMMSS.md`

## 🎯 What It Removes

### Fictional Characters
- **Anime/Manga:** SPY×FAMILY, Naruto, One Piece, Dragon Ball characters
- **Video Games:** Mario, Pokémon, Final Fantasy characters (full names only)
- **Cartoons:** Anpanman, Disney, Studio Ghibli characters
- **Metadata-Tagged:** Entries with `"is_fictional": "TRUE"`
- **Occupation-Based:** Entries with fictional occupations (架空のキャラクター, ヒーロー, etc.)

### Empty Entries
- Records with empty `person_name` field

## 🛡️ Safety Features

- **Automatic Backup:** Always creates backup before processing
- **False Positive Protection:** Advanced algorithm prevents removal of real people
- **Validation:** Comprehensive reporting for verification
- **Reversible:** Original data preserved in backup

## 🔧 Customization

### Adding New Fictional Characters
Edit the `fictional_patterns` dictionary in the script:

```python
'anime_manga': [
    'New Character Name',
    '新キャラクター',
    # Add more patterns...
]
```

### Preventing False Positives
Add entries to `false_positive_patterns`:

```python
('Pattern', 'RealName'),  # RealName contains Pattern but is not fictional
```

## 📝 Requirements

- Python 3.6+
- pandas
- Standard libraries (csv, json, os, re, datetime, pathlib)

## 💡 Pro Tips

1. **Always Check Reports:** Review the removal log before using cleaned data
2. **Test New Patterns:** Add a few entries at a time and verify results  
3. **Keep Backups:** The script creates backups, but keep additional copies for important data
4. **Monitor False Positives:** Check the removal log for legitimate people being removed

## 🆘 Troubleshooting

**No CSV files found:** Make sure you're in the directory with `ultra_think_*.csv` files

**Script errors:** Check that all required Python packages are installed:
```bash
pip install pandas
```

**Unexpected removals:** Check the removal log and add false positive patterns as needed
