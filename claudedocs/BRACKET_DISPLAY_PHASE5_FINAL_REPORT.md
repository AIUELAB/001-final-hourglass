## 🎯 発見された課題と対処

### 課題1: TERU(GLAY)での重複検出

**問題**:
エピソード本文が `"GLAYが30歳のとき、音楽業界で大きな転機を迎えた。"`で始まる

**根本原因**:
- LLMがグループ名を主語として使用
- プロンプトでの制約が不十分

**対処方針（今後の改善案）**:
1. プロンプトに明示的な制約を追加:
   ```
   【重要】「{bracket_word}」という単語は使用しないでください
   ```

2. 生成後の自動修正:
   - 括弧内ワードが主語になっている場合、人物名に置換
   - 例: "GLAYが" → "彼らが"

### 課題2: データベースの重複レコード

**問題**:
- さくらももこのレコードが2件存在（real_person と fictional_character）
- クエリ時にどちらを取得するか不定

**対処**:
- ✅ Phase 5-2で重複レコードを削除
- ✅ クエリにORDER BY優先度ルールを追加

### 課題3: Entity Typeの未設定

**問題**:
- モンキー・D・ルフィが `real_person` のまま

**対処**:
- ✅ Phase 5-2で正しく `fictional_character` に更新
- ✅ `primary_work = 'ONE PIECE'` を設定
