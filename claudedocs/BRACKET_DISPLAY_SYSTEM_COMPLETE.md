## 🎯 プロジェクト目標

エピソード生成システムに、人物名の後に括弧でグループ名・作品名を表示する機能を追加する。

### 要求仕様

1. **架空キャラクター**: 必ず作品名を表示
   - 例: `さくらももこ(ちびまる子ちゃん)`、`モンキー・D・ルフィ(ONE PIECE)`

2. **実在人物**: 条件付きでグループ名を表示
   - 条件: グループが活動中 AND グループの方が有名
   - 例: `又吉直樹(ピース)`、`hyde(L'Arc～en～Ciel)`

3. **重複制約**: 括弧内ワードはエピソード本文に出現しない
   - ❌ 悪い例: `上田晋也(くりぃむしちゅー)は...くりぃむしちゅーを結成した`
   - ✅ 良い例: `上田晋也(くりぃむしちゅー)は...コンビを結成した`

**問題**: `bracket_display_engine.py`は`person_name`を期待、データベースは`person_name_ja`

**修正**:
```python
bracket_input = {
    'person_name': person_data['person_name_ja'],  # キー変換
    'entity_type': person_data.get('entity_type'),
    # ... 他のフィールド
}
```

### 修正2: さくらももこの重複レコード

**問題**: `real_person`と`fictional_character`の2レコード存在

**修正**:
```sql
DELETE FROM persons
WHERE person_name_ja = 'さくらももこ'
AND entity_type = 'real_person'
```

### 修正3: モンキー・D・ルフィのentity_type未設定

**問題**: `real_person`のまま

**修正**:
```sql
UPDATE persons
SET entity_type = 'fictional_character',
    primary_work = 'ONE PIECE',
    show_group_in_bracket = 1,
    bracket_display_text = 'ONE PIECE'
WHERE person_name_ja = 'モンキー・D・ルフィ'
```
