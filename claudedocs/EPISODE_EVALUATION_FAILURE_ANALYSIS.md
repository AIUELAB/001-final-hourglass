### 1. **エピソード生成時の自動チェック**

```python
# エピソード品質チェック関数
def check_episode_quality(episode_text):
    checks = {
        "不安・葛藤": ["本当に", "不安", "葛藤", "心配"],
        "リスクテイキング": ["初めて", "断行", "無名", "前例なく"],
```

## 📌 まとめ

### 重要な発見

1. **エピソード内容が評価を決定する** - 同じ人物でも内容次第で合否が変わる
2. **不安・葛藤が最重要** - LLM評価で最も重視される要素
3. **数値の具体性が必須** - 曖昧な表現はスコアが低い
4. **ボーダーライン検出が機能** - 20-24点でLLM評価が自動トリガー

### 成功のカギ

✅ **不安・葛藤を明確に描写**
✅ **リスクテイキングを具体化**
✅ **センセーショナルな数値を含める**
✅ **転機・決断を明示する**
✅ **対象年齢を正確に設定**
