## 🔍 詳細分析: 各失敗タイプ

### タイプA: 感情欠落型

**定義**: 不安・葛藤・懸念が描写されていない

**症状**:
```
❌ 「映画『恋空』で興行収入39億円を記録した」
→ 成功事実のみ、不安なし

✅ 「本当にこの子で大丈夫？という制作側の不安の中」
→ 葛藤が明確
```

**スコア影響**:
- 共感性: 0/10 → 7/10（改善後）
- 合計: -7点〜-10点のインパクト

**検出キーワード**:
```python
ANXIETY_KEYWORDS = [
    "本当に", "不安", "懸念", "心配", "葛藤",
    "?", "だろうか", "できるのか"
]
```

**自動修正例**:
```python
if not has_anxiety_keywords(episode):
    insert_anxiety_phrase(
        template="「本当に{action}？」という{stakeholder}の不安の中"
    )
```

**実例**:
- 新垣結衣: 0/10 → 7/10（+7点）
- 松下幸之助: 0/10 → 推定7/10

---

### タイプB: リスク不明型

**定義**: 決断の困難さ、前例のなさ、リスクの大きさが伝わらない

**症状**:
```
❌ 「週休2日制を導入し、労働改革の先駆者となった」
→ リスクが見えない

✅ 「3ヶ月にわたる海外視察を断行した」
→ 「3ヶ月」「断行」でリスクが明確
```

**スコア影響**:
- リスクテイキング: 0/10 → 7/10（改善後）
- 意外性: 0/10 → 7/10（関連向上）
- 合計: -14点〜-20点のインパクト

**検出キーワード**:
```python
RISK_KEYWORDS = [
    "初めて", "前例なく", "無名", "断行",
    "挑戦", "賭け", "決断", "覚悟"
]

RISK_QUANTIFIERS = [
    r"\d+ヶ月",  # 期間
    r"\d+歳",    # 若さ・年齢
    "わずか", "たった", "全財産"
]
```

**自動修正例**:
```python
if not has_risk_indicators(episode):
    enhance_with_risk_context(
        templates=[
            "前例のない{action}に踏み切った",
            "わずか{period}で{achievement}",
            "{age}歳の無名{occupation}として"
        ]

```

**実例**:
- 新垣結衣: 「わずか3年の無名新人」追加 → 7/10
- 松下幸之助: 「3ヶ月の断行」「初めての海外視察」 → 7/10

### タイプC: 数値不足型

**定義**: センセーショナルな数値が不足または曖昧

**症状**:
```
❌ 「大ヒットを記録した」
→ 曖昧

✅ 「興行収入39億円を記録」「売上高1兆円企業」
→ 具体的
```

**スコア影響**:
- センセーショナル度: 0/10 → 7/10（改善後）
- 人生の転換点: 強化（+3点）
- 合計: -10点〜-13点のインパクト

**検出パターン**:
```python
NUMERICAL_PATTERNS = [
    r"\d+億円",           # 金額（億単位）
    r"\d+兆円",           # 金額（兆単位）
    r"\d+万人",           # 人数
    r"\d+%",              # パーセンテージ
    r"\d+ヶ月",           # 期間
    r"\d+倍",             # 倍率
    r"第\d+位",           # ランキング
]
```

**必要数値の種類**:
| カテゴリ | 例 | センセーショナル度 |
|---------|----|--------------------|
| **金額** | 39億円、1兆円 | 10/10 |
| **人数** | 10万人、20万人動員 | 7/10 |
| **期間** | 3ヶ月、わずか2年 | 7/10 |
| **成長率** | 20%向上、10倍 | 7/10 |
| **ランキング** | 第1位、歴代最多 | 10/10 |

**自動修正例**:

**実例**:

### タイプD: 転機曖昧型

**定義**: 人生の転換点・インパクトが不明確

**症状**:
```
❌ 「次世代の女優としての地位を確立した」
→ 抽象的

✅ 「大女優への階段を駆け上がった」
「日本の家電産業を世界水準に押し上げた」
→ 具体的インパクト
```

**スコア影響**:
- 人生の転換点: 7/10 → 10/10（改善後）
- センセーショナル度: +3点（関連向上）
- 合計: -3点〜-7点のインパクト

**検出キーワード**:
```python
TURNING_POINT_KEYWORDS = [
    "転機", "転換点", "分岐点",
    "決断", "決意", "踏み切った",
    "もたらした", "押し上げた", "切り開いた",
    "階段を駆け上がった", "道を開いた"
]
```

**強い表現 vs 弱い表現**:
| 弱い表現 | 強い表現 | スコア差 |
|---------|---------|----------|
| 「成功した」 | 「大ヒットを記録した」 | +2点 |
| 「認められた」 | 「業界に衝撃を与えた」 | +3点 |
| 「地位を確立」 | 「道を切り開いた」 | +3点 |
| 「貢献した」 | 「革命をもたらした」 | +4点 |

**自動修正例**:
```python
WEAK_TO_STRONG_MAP = {
    "成功した": "大ヒットを記録した",
    "評価された": "業界に衝撃を与えた",
    "確立した": "道を切り開いた",
}

def strengthen_impact(text):
    for weak, strong in WEAK_TO_STRONG_MAP.items():
        text = text.replace(weak, strong)
    return text
```

### タイプE: 年齢不一致型

**定義**: ユーザーの年齢とエピソードの年齢が一致しない

**症状**:
```
❌ ユーザー18歳 vs エピソード17歳
→ 即座に不合格

✅ ユーザー18歳 vs エピソード18歳
→ 通過
```

**スコア影響**:
- **全体失格**（Phase 1で停止）
- 他のスコアに関わらず不合格

**検出方法**:
```python
def validate_age(user_age: int, episode_age: int) -> bool:
    return user_age == episode_age
```

**自動修正例**:
```python
# エピソード生成時に年齢を強制
def generate_episode(person_name: str, target_age: int):

    {person_name}が{target_age}歳のときのエピソードを生成してください。

    重要: エピソードは必ず{target_age}歳時点の出来事にしてください。
    """
```

**実例**:
- 新垣結衣: 17歳エピソード → 18歳に修正で合格

```python
def auto_fix_episode(episode: str, failures: List[str]) -> str:
    # 優先順位順に修正
    for failure in sorted(failures, key=lambda f: PRIORITY_MAP.get(f, 99)):
        if failure == "A_ANXIETY_MISSING":
            episode = add_anxiety_phrase(episode)
        elif failure == "B_RISK_UNCLEAR":
            episode = add_risk_context(episode)
        elif failure == "C_NUMBERS_INSUFFICIENT":
            episode = add_specific_numbers(episode)
        elif failure == "D_TURNING_POINT_VAGUE":
            episode = strengthen_turning_point(episode)

    return episode
```
