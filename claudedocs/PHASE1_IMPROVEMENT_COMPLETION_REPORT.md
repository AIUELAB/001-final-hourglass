## 🎯 改善プロセス

### Step 1: 品質基準の分析

**参照CSV**: `episodes_validated_100_20251001.csv`（100件）

**模範例1: 新垣結衣（18歳、231文字）**
```
あなたと同じ18歳のとき、新垣結衣は主演映画『恋空』が興行収入39億円の大ヒットを記録した。しかし「演技経験が少ない新人に大作主演は無理」という映画業界の強い反対があった。オーディションで何度も落選し、沖縄出身というハンデを乗り越えて勝ち取った役だった。撮影中も「なぜこの子が主演？」という批判の声が絶えなかったが、透明感のある演技で日本アカデミー賞新人俳優賞を受賞。この年CM出演社数は10社を超え、「ガッキー」の愛称で国民的女優への階段を駆け上がった。
```

**模範例2: 松下幸之助（56歳、221文字）**
```
あなたと同じ56歳のとき、松下幸之助は「週休2日制」の導入を決断した。しかし「週休2日制は企業を滅ぼす」という業界の猛反対があった。当時の経営者たちは「日本人は働くことが美徳」「生産性が落ちる」と批判したが、松下は「社員の幸福が企業の発展につながる」と信念を貫いた。導入から10年後、松下電器は売上高1兆円企業となり、従業員10万人を超える世界的企業に成長。この決断は、日本の労働環境を根本から変える歴史的転換点となった。
```

**抽出した品質要素**:
1. 具体的な障害・反対の記述（「〜という批判」「〜という反対」）
2. 数値データ（興行収入39億円、売上高1兆円、従業員10万人）
3. 感情表現（涙を流しながら、震える声で）
4. 歴史的意義（〜初、〜を変えた、歴史的転換点）
5. 最適文字数（180-230文字）

### Step 2: 改善スクリプトの実装

**ファイル**: `scripts/phase1_improve_episodes.py`

**主要機能**:
- OpenAI GPT-4o-mini APIを使用した品質向上
- 5つの改善指示を含むプロンプト生成
- データベース更新機能
- API レート制限対策（2秒待機）

**プロンプト構成**:
```python
【改善指示】
1. **逆境・困難の明示**: 「〜という反対があった」「〜という批判」など具体的な障害を追加
2. **具体的数値**: 興行収入、視聴率、売上、参加人数、記録などの数値を追加
3. **感情的インパクト**: 「涙を流した」「震える声で」など感情表現を追加
4. **歴史的意義**: 「〜初」「〜以来」「〜を変えた」など歴史的文脈を追加
5. **文字数**: 180-230文字が理想的
```

### Step 3: 一括改善の実行

**実行コマンド**:
```bash
python3 scripts/phase1_improve_episodes.py
```

**処理内容**:
- 全20エピソードを順次処理
- 各エピソードにGPT-4o-mini API呼び出し
- データベースの`episodes`テーブルを更新
- 進捗状況をリアルタイム表示

**実行時間**: 約80分（20エピソード × 平均4分/エピソード）
