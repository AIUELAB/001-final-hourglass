## ⚠️ システムの課題

### 1. **初回合格率の不安定性**

**症状**: エピソード内容次第で評価が大きく変動
- 新垣結衣: 14点→36点（内容変更で合格）
- 松下幸之助: 17点→36点（内容変更で合格）

**原因**:
- プロンプトに「不安・葛藤」の必須性が明記されていない
- リスクテイキングの具体化指示が不足
- センセーショナル度の数値要件が曖昧

### 2. **評価基準の暗黙性**

**問題**: 合格ラインが明示的でない
```python
# 現状の評価
if keyword_score >= 20 and llm_score >= 30:
    return "PASS"  # 合計50点以上必要
```

**欠点**:
- 生成時に50点基準が伝わっていない
- 「転換点7点、意外性7点...」の配点が不明
- 具体例（新垣結衣の合格版）が参照されていない

### 3. **プロンプトとルールの乖離**

**現象**: 生成プロンプトと評価ルールが別管理
- 生成: `high_quality_episode_generator.py`
- 評価: `hybrid_impact_evaluator.py`
- **フィードバックループが弱い**

### 4. **Few-Shot Learningの未活用**

**機会損失**: 既に100個の合格エピソードが存在
- episodes_validated_100_20251001.csv
- 成功パターンが蓄積されている
- しかし生成時に参照されていない

## 🎯 改善の方向性

### 1. **プロンプトの明示的強化**

**現状**:
```python
# 曖昧な指示
"エピソードを生成してください"
```

**改善後**:
```python
# 明示的な指示
"""
以下の要素を必ず含めてください:
1. 不安・葛藤: "本当に〜？"という懸念
2. リスクテイキング: 具体的な挑戦（期間、前例なし等）
3. センセーショナル度: 具体的数値（金額、人数、期間）
4. 転機の明示: "〜をもたらした"
5. 5要素で各7点以上を目指す
"""
```

### 2. **Few-Shot Learningの実装**

**戦略**: 合格エピソードを例示に使用
```python
# 成功例を3-5個提示
examples = [
    "新垣結衣（18歳）: 36点合格",
    "松下幸之助（56歳）: 36点合格",
    "イチロー（45歳）: 高評価",
]

prompt = f"""
以下の高評価エピソードを参考に生成してください:
{examples}

共通点:
- 不安・葛藤が明確
- リスクテイキングが具体的
- センセーショナルな数値
"""
```

### 3. **リアルタイムフィードバック**

**改善ループの強化**:
```python
# 生成 → 評価 → 改善 → 再評価
for iteration in range(max_iterations):
    episode = generate(prompt)
    evaluation = evaluate(episode)

    if evaluation.score >= 50:
        break

    # 具体的な改善指示
    improvements = [
        f"不安・葛藤を追加: {example}",
        f"リスクを具体化: {example}",
        f"数値を明確化: {example}"
    ]

    prompt = update_prompt(prompt, improvements)
```

### 4. **品質ゲートの事前実装**

**生成時チェック**:
```python
# 生成前に要件確認
quality_checklist = {
    "不安・葛藤キーワード": ["本当に", "不安", "懸念"],

    "数値": ["億円", "万人", "ヶ月"],
```
