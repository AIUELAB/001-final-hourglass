## 🔧 App Store Connect 入力手順

### Step 1: アプリ情報の入力

1. [App Store Connect](https://appstoreconnect.apple.com) にログイン
2. **マイ App** → **最期の砂時計** を選択（または新規作成）
3. **App 情報** タブで以下を入力:

```
アプリ名: 最期の砂時計
サブタイトル: 残り時間を見える化する
カテゴリ: ライフスタイル
セカンダリカテゴリ: ヘルスケア/フィットネス
コンテンツの権利: このAppのすべてのコンテンツについて...の権利を所有している
年齢制限指定: 4+
```

### Step 2: 価格と配信地域

1. **価格および配信状況** タブを選択
2. 価格: **無料**
3. 配信地域: **日本**（必要に応じて追加）

### Step 3: バージョン情報の入力

1. **App Store** タブ → **1.0.1** を選択
2. 以下を入力:

#### スクリーンショット

1. **iPhone 6.7インチディスプレイ** セクション
2. 5枚のスクリーンショットをドラッグ&ドロップ

#### 説明文

```
人生の「残り時間」を意識したことはありますか？

「最期の砂時計」は、あなたの推定寿命をもとに、残された時間を視覚的に表示するアプリです。

■ 主な機能

【砂時計表示】
生年月日と健康情報から推定された残り時間を、美しい砂時計のアニメーションで表示します。

【エピソード】
同年代の著名人たちが、その年齢で何を成し遂げたかを知ることができます。彼らの人生のエピソードから、インスピレーションを得てください。

【健康スコア】
喫煙、飲酒、運動習慣、睡眠時間などの生活習慣から、あなたの健康スコアを算出。改善のヒントも提供します。

【プライバシー重視】
すべてのデータはお使いのデバイス内に保存されます。外部サーバーへの送信は一切ありません。

■ こんな方におすすめ

- 時間の大切さを実感したい方
- 目標に向かって行動したい方
- 健康的な生活習慣を身につけたい方
- 人生の節目を迎えている方

■ 注意事項

本アプリで表示される寿命は、統計データに基づく推定値であり、医学的な診断ではありません。あくまで参考値としてご利用ください。
```

#### キーワード

```
寿命,残り時間,人生,砂時計,ライフ,タイマー,健康,モチベーション,目標,時間管理
```

#### リリースノート

- 42件のE2Eテストで品質を担保

#### URL設定

マーケティングURL: （空欄可）

### Step 4: App Privacyの設定

1. **App のプライバシー** セクションに移動
2. **データ収集とプライバシー** → **開始する**
3. 質問: 「このAppでユーザからデータを収集しますか？」
4. 回答: **いいえ、このAppではデータを収集していません**
5. **公開** をクリック

### Step 5: 審査情報の入力

1. **App 審査情報** セクション
2. 連絡先情報を入力

#### レビューメモ

```
テスト手順:
1. アプリを起動
2. オンボーディングで生年月日を入力
3. 砂時計画面で残り時間を確認
4. エピソードタブで著名人のエピソードを閲覧
5. プロフィールタブで健康情報を入力

免責事項:
本アプリで表示される寿命は統計データに基づく推定値であり、医学的な診断や予測ではありません。ユーザーに対して明確にこの点を説明しています。
```

#### デモアカウント

- **デモアカウント不要**: ログイン機能なし

## 🚀 提出手順

### Step 1: ビルドの選択

1. **ビルド** セクションで **+** をクリック
2. TestFlightにアップロードされたビルドを選択
3. **完了** をクリック

### Step 2: 最終確認

1. 全てのセクションに緑のチェックマークがついていることを確認
2. 赤いエラーマークがあれば修正

### Step 3: 審査に提出

1. **審査に提出** ボタンをクリック
2. 確認ダイアログで **提出** をクリック

---

## ⏱️ 審査後の対応

### 審査期間

- 通常: 24〜48時間
- 最大: 7日間

### 審査結果

| 結果 | 対応 |
|------|------|
| **承認** | App Storeで公開可能に |
| **却下** | 却下理由を確認し修正 |
| **メタデータ却下** | メタデータのみ修正して再提出 |

### よくある却下理由

| 理由 | 対策 |
|------|------|
| クラッシュ | TestFlightで十分にテスト |
| 不完全な機能 | 全機能が動作することを確認 |
| プライバシー違反 | Privacy Manifest を正しく設定 |
| 不適切なメタデータ | 説明文と実際の機能を一致させる |
