## 7. 職業カテゴリ付き名前の禁止

### ルール
人物名に職業/カテゴリを含めない。

**禁止例**: `歌舞伎・市川海老蔵`, `落語家・立川談志`
**正しい例**: `市川海老蔵`, `立川談志`

### 禁止プレフィックス
歌舞伎, 落語, 漫才, 俳優, 女優, 歌手, 作家, 画家, 音楽家, 政治家, 科学者,
哲学者, 漫画家, 小説家, 詩人, 映画監督, 実業家, 武将, 大名 等

### 検出
```bash
python scripts/detect_person_id_duplicates.py
```

---

## 8. グループ/バンド名の人物登録禁止

### ルール
グループ・バンド・団体名を人物として登録しない。
エピソードは特定のメンバーに帰属させる。

**禁止例**: `サカナクション`, `ビートルズ`, `AKB48`
**正しい例**: `山口一郎`, `ジョン・レノン`, `前田敦子`

---

## 9. 説明文の人物名登録禁止

### ルール
説明文・肩書きを人物名として登録しない。

**禁止例**: `間宮海峡発見者・間宮林蔵の弟子`, `〇〇の父`, `〇〇の妻`
**対応**: 実在人物名が特定できれば修正、不明なら削除

### 統合手順
```python
# 1. 重複確認
df[df['person_name'].isin(['ビートたけし', '北野武'])].groupby('person_id').size()

# 2. ID統合
df.loc[df['person_id'] == OLD_ID, 'person_id'] = NEW_ID
df.loc[df['person_id'] == NEW_ID, 'person_name'] = CANONICAL_NAME
```

### 検出スクリプト
```bash
python scripts/detect_person_id_duplicates.py
```

## 10. エピソード品質ゲート

### ルール
1. **メタ表現禁止**: 「あなたと同じ」「あなたが」等の読者呼びかけ禁止
2. **時系列整合**: 1エピソード=1年齢/1年。「翌年」「数年後」は別EPへ
3. **事実検証**: 出典なし断定禁止。fact_check_result=未確認は要注意

### 検出・検証
```bash
# 品質チェック
python scripts/validate_episode_quality.py

# 回帰テスト
pytest tests/test_episode_quality_gate.py -v
```

## 9. 人物名表記揺れ防止（自動検出）

### ルール
新規人物登録時、既存人物との表記揺れ（ヴ/ブ等）を自動検出してブロック。

### 検出対象
- ヴ ↔ ブ（ヴァ/バ、ヴィ/ビ、ヴェ/ベ、ヴォ/ボ）
- 中点・スペースの有無
- 長音記号の揺れ

### 検証スクリプト
```bash
# 全体スキャン
python scripts/validators/person_name_duplicate_validator.py

# 特定の名前をチェック
python scripts/validators/person_name_duplicate_validator.py --check "エルビス・プレスリー"
```

### 自動実行
- pre-commit: マスターCSV変更時に自動チェック
- 回帰テスト: `tests/test_person_name_duplicates.py`

## 10. グループ自己参照の禁止

### ルール
グループ/コンビ自体のエピソードでは、`group_name`に自分自身を設定しない。

### 誤った例
```
person_name: 博多華丸・大吉
group_name: 博多華丸・大吉  ← 自己参照（NG）
is_group_member: True       ← グループ自体なのでFalseであるべき
```

### 正しい例
```
person_name: 博多華丸・大吉
group_name: 未登録          ← グループ自体なので不要
is_group_member: False      ← グループ自体
```

### 修正対象（2025-12-24）
35件の自己参照を一括修正:
- 博多華丸・大吉、見取り図、アインシュタイン、BAD HOP、ゆでたまご
- ダフト・パンク、中川家、世界のナベアツ、ワンダイレクション 等

## 11. エピソードは個人専用（グループ/コンビ名禁止）

### ルール
**エピソードは必ず個人（一人の人物）に帰属させる。**
グループ名・コンビ名でのPERSON ID登録は禁止。

### 理由
アプリユーザーは個人であり、自分の年齢と人物の年齢を比較する。
グループ/コンビには「年齢」が存在しないため、エピソードの対象として不適切。

### 禁止例
| 禁止 | 正しい例 |
|------|----------|
| 博多華丸・大吉 | 博多華丸 または 博多大吉 |
| 見取り図 | 盛山晋太郎 または リリー |
| ワンダイレクション | ハリー・スタイルズ 等 |
| ダフト・パンク | （削除、または個人特定後に登録） |

### 対応方法
1. **個人特定可能**: エピソード内容から主人公を特定し、個人名に変更
2. **個人特定不可**: エピソードを削除

### 職業名プレフィックス禁止
「職業名+人物名」形式も禁止。検出対象：
- `狂言師`, `歌舞伎役者`, `落語家` 等

### 企業名プレフィックス禁止
「企業名+人物名」形式も禁止。検出対象：
- `日本電産`, `キヤノン`, `サントリー`, `ユニクロ`, `トヨタ`, `ソニー` 等
- `コナミ・`, `フェイスブック・`, `Google・` 等（中点つき）

### 検出・予防（3層構造）

```
┌─────────────────────────────────────────────────────────┐
│ [Layer 1] ブラックリスト検出        → ERROR (即時ブロック) │
│   既知のグループ名、プレフィックスパターン                  │
├─────────────────────────────────────────────────────────┤
│ [Layer 2] ヒューリスティック検出    → WARNING (要レビュー) │
│   構造的パターン分析で未知の問題を事前検出                  │
├─────────────────────────────────────────────────────────┤
│ [Layer 3] Wikidataバッチ検証       → レポート生成         │
│   定期実行で外部データと照合                               │
└─────────────────────────────────────────────────────────┘
```

```bash
# グループ/コンビ名チェック
python scripts/validators/group_name_validator.py

# 特定の名前をチェック
python scripts/validators/group_name_validator.py --check "博多華丸・大吉"

# CI/pre-commit用（違反があればexit 1）
python scripts/validators/group_name_validator.py --strict

# Wikidataで名前を確認（Layer 3）
python scripts/validators/wikidata_group_checker.py --check "チェッカーズ"
```

### Layer 2 ヒューリスティックパターン
未知のグループ名を構造的に検出：
- `group_individual`: グループ名・個人名形式
- `job_title_prefix`: 職業名+個人名形式
- `company_suffix`: 企業名+個人名形式
- `role_prefix`: 役職名+個人名形式

### 自動実行
- **pre-commit**: マスターCSV変更時に自動チェック
- **回帰テスト**: `tests/test_group_name_prevention.py`
