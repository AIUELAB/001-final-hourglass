## 7. 職業カテゴリ付き名前の禁止

### ルール
人物名に職業/カテゴリを含めない。

**禁止例**: `歌舞伎・市川海老蔵`, `落語家・立川談志`
**正しい例**: `市川海老蔵`, `立川談志`

歌舞伎, 落語, 漫才, 俳優, 女優, 歌手, 作家, 画家, 音楽家, 政治家, 科学者,
哲学者, 漫画家, 小説家, 詩人, 映画監督, 実業家, 武将, 大名 等

### 検出
```bash
python scripts/detect_person_id_duplicates.py
```

## 8. グループ/バンド名の人物登録禁止

### ルール
グループ・バンド・団体名を人物として登録しない。
エピソードは特定のメンバーに帰属させる。

**禁止例**: `サカナクション`, `ビートルズ`, `AKB48`
**正しい例**: `山口一郎`, `ジョン・レノン`, `前田敦子`

## 9. 説明文の人物名登録禁止

### ルール
説明文・肩書きを人物名として登録しない。

**禁止例**: `間宮海峡発見者・間宮林蔵の弟子`, `〇〇の父`, `〇〇の妻`
**対応**: 実在人物名が特定できれば修正、不明なら削除

### 統合手順
```python
# 1. 重複確認
df[df['person_name'].isin(['ビートたけし', '北野武'])].groupby('person_id').size()

# 2. ID統合
df.loc[df['person_id'] == OLD_ID, 'person_id'] = NEW_ID
df.loc[df['person_id'] == NEW_ID, 'person_name'] = CANONICAL_NAME
```

### 検出スクリプト
```bash
python scripts/detect_person_id_duplicates.py
```

## 10. グループ自己参照の禁止

### ルール
グループ/コンビ自体のエピソードでは、`group_name`に自分自身を設定しない。

### 誤った例
```
person_name: 博多華丸・大吉
group_name: 博多華丸・大吉  ← 自己参照（NG）
is_group_member: True       ← グループ自体なのでFalseであるべき
```

### 正しい例
```
person_name: 博多華丸・大吉
group_name: 未登録          ← グループ自体なので不要
is_group_member: False      ← グループ自体
```

### 修正対象（2025-12-24）
35件の自己参照を一括修正:
- 博多華丸・大吉、見取り図、アインシュタイン、BAD HOP、ゆでたまご
- ダフト・パンク、中川家、世界のナベアツ、ワンダイレクション 等

## 11. エピソードは個人専用（グループ/コンビ名禁止）

### ルール
**エピソードは必ず個人（一人の人物）に帰属させる。**
グループ名・コンビ名でのPERSON ID登録は禁止。

### 理由
アプリユーザーは個人であり、自分の年齢と人物の年齢を比較する。
グループ/コンビには「年齢」が存在しないため、エピソードの対象として不適切。

### 禁止例
| 禁止 | 正しい例 |
|------|----------|
| 博多華丸・大吉 | 博多華丸 または 博多大吉 |
| 見取り図 | 盛山晋太郎 または リリー |
| ワンダイレクション | ハリー・スタイルズ 等 |
| ダフト・パンク | （削除、または個人特定後に登録） |

### 対応方法
1. **個人特定可能**: エピソード内容から主人公を特定し、個人名に変更
2. **個人特定不可**: エピソードを削除

### 検出・予防（3層構造）

```
┌─────────────────────────────────────────────────────────┐
│ [Layer 1] ブラックリスト検出        → ERROR (即時ブロック) │
│   既知のグループ名、プレフィックスパターン                  │
├─────────────────────────────────────────────────────────┤
│ [Layer 2] ヒューリスティック検出    → WARNING (要レビュー) │
│   構造的パターン分析で未知の問題を事前検出                  │
├─────────────────────────────────────────────────────────┤
│ [Layer 3] Wikidataバッチ検証       → レポート生成         │
│   定期実行で外部データと照合                               │
└─────────────────────────────────────────────────────────┘
```

```bash
# グループ/コンビ名チェック
python scripts/validators/group_name_validator.py

# 特定の名前をチェック
python scripts/validators/group_name_validator.py --check "博多華丸・大吉"

# CI/pre-commit用（違反があればexit 1）
python scripts/validators/group_name_validator.py --strict

# Wikidataで名前を確認（Layer 3）
python scripts/validators/wikidata_group_checker.py --check "チェッカーズ"
```

### Layer 2 ヒューリスティックパターン
未知のグループ名を構造的に検出：
- `group_individual`: グループ名・個人名形式
- `job_title_prefix`: 職業名+個人名形式
- `company_suffix`: 企業名+個人名形式
- `role_prefix`: 役職名+個人名形式

## 12. 架空キャラクターのカノン検証（2026-01-03追加）

### ルール
架空キャラクターのエピソードは、原作/映画の設定（カノン）に準拠する必要がある。

### 禁止事項
1. **一般的キャリア文**: 物語固有性が低いテンプレート表現
   - 「専門性の確立」「後進への指導者」「コミュニケーションの重要性」
   - 「キャリアとバランス」「精神的な支え」「転換期となりました」

2. **不自然な年齢設定**: 動物/非人間キャラに成人年齢(25-60歳)
   - 例: ジジ(猫)に30歳、スヌーピー(犬)に30歳

3. **カノンに存在しない創作**: 原作/映画に描写されていない出来事
   - 例: ジジが「後進の魔女を指導」（原作に存在しない）

### 削除ケース

|------|-----------|-------------|------|
| 2026-01-03 | E441CD69E | ジジ | カノン非準拠・一般的キャリア文混入 |

2. **成人年齢(25-60歳)の機械的割り当て**: 特に禁止

## 16. 日本人名の正規化（2026-01-03追加）

### ルール
日本人は**漢字表記**を正式名として登録する。

### 禁止表記
| パターン | 禁止例 | 正しい例 |
|----------|--------|----------|
| ローマ字 | Akira Kurosawa | 黒澤明 |
| カタカナ音訳 | アキラ・クロサワ | 黒澤明 |
| ローマ字カタカナ混在 | Hayao ミヤザキ | 宮崎駿 |

### 例外
- 芸名がカタカナの場合: タモリ、HIKAKIN、あいみょん 等
- 公式にローマ字を使用する場合: YOSHIKI、SUGIZO 等
- 外国籍の日本在住者: ラモス瑠偉 等

### 根本原因（黒澤明重複問題）
```
P3159F6D "アキラ・クロサワ" ←── 非標準（ローマ字のカタカナ音訳）
         ↓
         検出されず重複発生
         ↓
PBC4ECE7 "黒澤明" ←── 正式（漢字表記）
```

詳細: `src/reports/kurosawa_root_cause_analysis_20260103.md`

### 既知エイリアス（KNOWN_ALIASES）
監督、作家、漫画家、音楽家、科学者、実業家、歴史的人物のローマ字表記を登録済み。

| カテゴリ | 例 |
|----------|-----|
| 映画監督 | Akira Kurosawa→黒澤明, Hayao Miyazaki→宮崎駿 |
| 作家 | Haruki Murakami→村上春樹, Yukio Mishima→三島由紀夫 |
| 漫画家 | Osamu Tezuka→手塚治虫, Akira Toriyama→鳥山明 |
| 音楽家 | Ryuichi Sakamoto→坂本龍一, Yoko Ono→オノ・ヨーコ |
| 実業家 | Soichiro Honda→本田宗一郎, Akio Morita→盛田昭夫 |
| 歴史人物 | Nobunaga Oda→織田信長, Ieyasu Tokugawa→徳川家康 |

### 検出アルゴリズム
1. **ローマ字パターン検出**: `^[A-Z][a-z]+ [A-Z][a-z]+$` 形式
2. **日本人姓リスト照合**: Kurosawa, Miyazaki, Murakami 等
3. **Wikidata照合**: 日本語ラベルを自動取得

### 検証スクリプト
```bash
# 全件スキャン
python scripts/validators/japanese_name_normalizer.py

# 特定の名前をチェック
python scripts/validators/japanese_name_normalizer.py --check "Akira Kurosawa"

# Wikidata照合なし（高速）
python scripts/validators/japanese_name_normalizer.py --no-wikidata
```

### 再発防止
- **pre-commit hook**: ローマ字/カタカナ音訳の日本人名をブロック
- **KNOWN_ALIASES拡充**: 著名人を継続的に追加
- **Wikidata統合**: 正式名を自動確認

### 村上春樹問題（v6採用の根拠）

**問題**: v5では「物語性」が過大評価され、社会的インパクトの大きいイベントが低くスコアリングされていた。

| エピソード | v5スコア | v6スコア | 期待 |
|------------|----------|----------|------|
| 35歳『ノルウェイの森』発表 | 60.13 | **77.76** | 高い |
| 38歳 重圧からの逃避 | 61.52 | 77.46 | 低い |

v6では正しく「発表 > 逃避」となるため、v6を採用。

詳細: `src/reports/murakami_score_reversal_analysis_20260103.md`
