# エピソード評価ルーブリック（ゴールドスタンダード用）

> **目的**: 評価者間で一貫した採点を行うための明確な基準を定義する
> **作成日**: 2025-12-19
> **対象**: 50件のゴールドスタンダードサンプル

---

## 評価の基本方針

### 評価者への注意事項

1. **独立評価**: 他の評価者の結果を見ずに評価する
2. **順序ランダム化**: サンプルは番号順ではなくランダム順で評価する
3. **休憩**: 25件ごとに5分以上の休憩を取る
4. **理由記載**: 各評価に簡潔な理由（1-2文）を記載する
5. **迷った場合**: 中央値（5点）を避け、どちらかに寄せて判断する

### スコアスケール

各軸は **1〜10点** で評価する。

| 点数帯 | 意味 |
|--------|------|
| 9-10点 | 非常に優れている（上位10%レベル） |
| 7-8点 | 優れている（上位30%レベル） |
| 5-6点 | 普通（平均的） |
| 3-4点 | やや劣る（下位30%レベル） |
| 1-2点 | 劣る（下位10%レベル） |

## 軸1: 記憶性スコア（Memorability）

**定義**: 読んだ後、読者の記憶に残りやすいか

### 評価基準

| 点数 | 基準 | 具体例 |
|------|------|--------|
| **10** | 読んだら忘れられない。具体的で鮮明なイメージが残る | 具体的な数字・固有名詞・ドラマチックな転機が複数ある |
| **9** | 非常に記憶に残る。複数の印象的な要素がある | 「15歳で初めて〇〇」のような具体的な転機 |
| **8** | 記憶に残りやすい。1つ以上の印象的な要素がある | 具体的な年号や数値、固有名詞が含まれる |
| **7** | やや記憶に残る。特徴的な要素がある | 特定の出来事や人物名が明記されている |
| **6** | 普通。読めば覚えられるが、特に印象的ではない | 一般的な出来事の記述 |
| **5** | あまり記憶に残らない。具体性に欠ける | 抽象的な表現が多い |
| **4** | 記憶に残りにくい。漠然としている | 「頑張った」「成功した」等の抽象表現のみ |
| **3** | ほぼ記憶に残らない。特徴がない | 具体的な情報がほとんどない |
| **2** | 記憶に残らない。平板な記述 | 事実の羅列のみ |
| **1** | 全く記憶に残らない。内容が薄い | 意味のある情報がない |

### チェックポイント

- [ ] 具体的な数値（年号、年齢、金額、記録）があるか
- [ ] 固有名詞（人名、地名、作品名）があるか
- [ ] 「初めて」「転機」「決定的」等の転換点があるか
- [ ] 視覚的にイメージできる描写があるか

## 軸2: 共感性スコア（Empathy）

**定義**: 読者が感情的に共鳴できるか、自分事として感じられるか

### 評価基準

| 点数 | 基準 | 具体例 |
|------|------|--------|
| **10** | 深く共感できる。自分の経験と重ね合わせられる | 普遍的な感情（挫折、成長、愛）が具体的に描かれる |
| **9** | 強く共感できる。感情が伝わってくる | 人物の心情が丁寧に描写されている |
| **8** | 共感できる。感情的なつながりを感じる | 「不安」「喜び」等の感情が明示されている |
| **7** | やや共感できる。人物の気持ちが理解できる | 感情表現があるが、やや表面的 |
| **6** | 普通。共感の余地はあるが強くない | 感情より事実の記述が中心 |
| **5** | あまり共感できない。感情的な距離を感じる | 感情表現が乏しい |
| **4** | 共感しにくい。人物の内面が見えない | 出来事の記述のみで感情がない |
| **3** | ほぼ共感できない。無機質な記述 | 事実の羅列 |
| **2** | 共感できない。感情的なつながりがない | 内容が技術的・客観的すぎる |
| **1** | 全く共感できない。人間味がない | 機械的な記述 |

### チェックポイント

- [ ] 人物の感情・心情が描かれているか
- [ ] 困難・挫折・葛藤があるか
- [ ] 読者が「自分も同じ気持ちになる」と思えるか
- [ ] 普遍的なテーマ（成長、挑戦、愛）があるか

## 軸3: 意外性スコア（Surprise）

**定義**: 予想外の展開や驚きがあるか

### 評価基準

| 点数 | 基準 | 具体例 |
|------|------|--------|
| **10** | 非常に驚く。予想を大きく裏切る展開 | 「〇〇で有名な人が、若い頃は△△だった」 |
| **9** | かなり驚く。意外な事実がある | 常識とは逆の行動・結果 |
| **8** | 驚きがある。予想とは異なる要素がある | 「実は〇〇だった」系の情報 |
| **7** | やや意外。新しい発見がある | 知られていない逸話 |
| **6** | 普通。驚きはないが興味深い | 予想通りだが詳細が面白い |
| **5** | あまり意外ではない。想定内 | 典型的な成功ストーリー |
| **4** | 意外性がない。予想通り | ステレオタイプな記述 |
| **3** | ほぼ意外性がない。ありきたり | よくある話 |
| **2** | 意外性がない。退屈 | 予想を裏切らない平凡な記述 |
| **1** | 全く意外性がない。陳腐 | クリシェ（使い古された表現）のみ |

### チェックポイント

- [ ] 「え？そうなの？」と思える要素があるか
- [ ] ステレオタイプを覆す内容があるか
- [ ] 逆説・対比・ギャップがあるか
- [ ] 知られていない逸話・事実があるか

## 軸4: 生成品質スコア（Generation Quality）

**定義**: 文章として自然で、読みやすく、完成度が高いか

### 評価基準

| 点数 | 基準 | 具体例 |
|------|------|--------|
| **10** | 完璧な文章。プロの執筆レベル | 流れが自然、語彙が豊富、推敲されている |
| **9** | 非常に高品質。洗練されている | 文章構成が巧み、表現が的確 |
| **8** | 高品質。読みやすく整っている | 文法・語彙に問題なし、流れが自然 |
| **7** | 良好。若干の改善余地あり | 読みやすいが、やや冗長な部分あり |
| **6** | 普通。標準的な品質 | 特に問題はないが、特筆すべき点もない |
| **5** | やや劣る。改善の余地あり | 文章の流れがやや不自然 |
| **4** | 劣る。問題がある | 文法ミス、不自然な表現、重複 |
| **3** | 品質が低い。読みにくい | 文章の構成が悪い、意味が取りにくい |
| **2** | 品質が非常に低い | 文法ミス多数、意味不明な部分あり |
| **1** | 品質が最低 | 読むに堪えない |

### チェックポイント

- [ ] 文法・語法に誤りがないか
- [ ] 文章の流れが自然か
- [ ] 冗長・重複がないか
- [ ] 語彙が適切か（子供っぽい/難解すぎない）
- [ ] 「〜である」「〜だ」の統一、敬体・常体の統一

## 軸5: 教育的価値（Educational Value）

**定義**: 読者が何かを学べるか、教訓や知識を得られるか

### 評価基準

| 点数 | 基準 | 具体例 |
|------|------|--------|
| **10** | 非常に教育的。深い学びがある | 人生訓、歴史的知識、専門知識が複数 |
| **9** | 教育的価値が高い。明確な学びがある | 「〇〇から△△を学んだ」が明示 |
| **8** | 教育的。知識や教訓が得られる | 事実情報+その意義の説明 |
| **7** | やや教育的。参考になる点がある | 事実情報は多いが、教訓は暗示的 |
| **6** | 普通。多少の学びはある | 基本的な事実情報のみ |
| **5** | あまり教育的でない。学びが少ない | エピソードのみで、教訓なし |
| **4** | 教育的価値が低い | 感情的な記述中心、事実が少ない |
| **3** | ほぼ教育的価値がない | 学べる要素がない |
| **2** | 教育的価値がない | 内容が薄い |
| **1** | 全く教育的価値がない | 意味のある情報がない |

### チェックポイント

- [ ] 事実情報（年号、出来事、人物）があるか
- [ ] 教訓・学びが明示または暗示されているか
- [ ] 読者が「なるほど」と思えるか
- [ ] 専門知識や歴史的背景の説明があるか

---

## 軸6: ストーリー品質（Story Quality）

**定義**: 物語として構成が整っているか、起承転結があるか

### 評価基準

| 点数 | 基準 | 具体例 |
|------|------|--------|
| **10** | 完璧なストーリー。起承転結が明確 | 導入→展開→転機→結末が美しく構成 |
| **9** | 非常に良いストーリー。流れが秀逸 | 明確な構成、クライマックスあり |
| **8** | 良いストーリー。構成が整っている | 始まり・中間・終わりが明確 |
| **7** | やや良いストーリー。流れがある | 構成はあるが、やや平板 |
| **6** | 普通。ストーリーとして成立 | 時系列で出来事が並んでいる |
| **5** | あまり良くない。構成が弱い | 転機・クライマックスが不明確 |
| **4** | 構成が悪い。流れが不自然 | 出来事の羅列、つながりが弱い |
| **3** | ストーリーとして成立しない | 断片的な情報のみ |
| **2** | ストーリー性がない | 箇条書き的な記述 |
| **1** | 全くストーリー性がない | 意味のあるまとまりがない |

### チェックポイント

- [ ] 導入（状況設定）があるか
- [ ] 展開（出来事の進行）があるか
- [ ] 転機（変化・クライマックス）があるか
- [ ] 結末（結果・影響）があるか
- [ ] 時系列が明確か

---

## 軸7: 事実密度（Fact Density）

**定義**: 検証可能な事実情報がどれだけ含まれているか

### 評価基準

| 点数 | 基準 | 具体例 |
|------|------|--------|
| **10** | 非常に高密度。検証可能な事実が多数 | 年号、数値、人名、地名、作品名が5つ以上 |
| **9** | 高密度。事実情報が豊富 | 検証可能な情報が4つ以上 |
| **8** | 密度が高い。事実が複数ある | 検証可能な情報が3つ以上 |
| **7** | やや高密度。事実がいくつかある | 検証可能な情報が2つ以上 |
| **6** | 普通。基本的な事実がある | 年齢、時期など基本情報のみ |
| **5** | やや低密度。事実が少ない | 検証可能な情報が1つのみ |
| **4** | 低密度。事実がほとんどない | 抽象的な記述が中心 |
| **3** | 密度が非常に低い | 具体的な情報がない |
| **2** | 事実がない | 感情・印象のみ |
| **1** | 情報がない | 内容が空疎 |

### チェックポイント

- [ ] 年号・年代があるか
- [ ] 具体的な数値（金額、記録、人数）があるか
- [ ] 固有名詞（人名、地名、作品名、組織名）があるか
- [ ] 検証可能な出来事があるか

## 評価シートの記入方法

### 必須記入項目

1. **評価者ID**: 匿名のID（評価者A、B、C等）
2. **サンプルNo**: 1〜50
3. **各軸スコア**: 1〜10の整数
4. **評価理由**: 各軸について1-2文の簡潔な理由

### 記入例

```
サンプルNo: 12
記憶性: 8 - 「15歳で初めてギターを手にした」という具体的な転機がある
共感性: 7 - 挫折からの復活が描かれ、共感できる
意外性: 6 - 音楽家の成功ストーリーとしては典型的
生成品質: 8 - 文章が流れるように読める、文法ミスなし
教育的価値: 7 - 継続することの大切さを学べる
ストーリー品質: 8 - 起承転結が明確
事実密度: 7 - 年齢、作品名、受賞歴が含まれる
```

## 評価者間一致度の検証

### Krippendorff's α の目標

| α値 | 解釈 |
|-----|------|
| α ≥ 0.80 | 高い一致（理想） |
| 0.67 ≤ α < 0.80 | 許容範囲 |
| α < 0.67 | 要改善（ルーブリック修正） |

### 不一致時の対応

1. α < 0.67 の軸について、評価者間で議論
2. ルーブリックの基準を明確化
3. 再評価（不一致サンプルのみ）

## 付録: 参考スコアの非公開

評価者には現行の機械スコア（CSV記載値）を見せない。
評価後に相関を検証し、機械スコアの妥当性を判定する。

**検証項目**:
- 人手評価の平均と機械スコアのPearson相関係数
- 軸ごとの相関差異
- 相関が低い軸の原因分析
