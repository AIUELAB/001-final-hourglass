## 1. 現状の課題

### 1.1 LLMスコアの低分散問題

LLM（Claude等）による評価は以下の特性がある:
- 極端な点数を避ける傾向（5-8点に集中）
- デフォルト値7.5に回帰しやすい
- 評価基準が曖昧だとスコアが収束

**結果**: ルールベースσ=0.5-1.0に対し、LLMスコアσ=0.2-0.3程度

### 1.2 現在のマッピング問題

```python
# 現在の単純マッピング（3軸→7軸）
llm_mapped = {
    "記憶性": (empathy + surprise) / 2,  # 2軸平均
    "共感性": empathy,                    # 直接
    "意外性": surprise,                   # 直接
    "生成品質": story_quality,            # 直接
    "教育的価値": empathy,                # 共感性と同一（問題）
    "ストーリー品質": story_quality,      # 生成品質と同一（問題）
    "事実密度": 7.5,                      # 固定値
}
```

**問題点**:
- 教育的価値 = 共感性（独立性なし）
- ストーリー品質 = 生成品質（独立性なし）

### 2.2 Phase 7B: スケール補正（分散維持）

LLMスコアをルールベースの分布に合わせてスケール補正:

```python
def calibrate_llm_score(llm_score: float, axis: str) -> float:
    """
    LLMスコアをルールベース分布に合わせてキャリブレーション

    LLMは7.5付近に集中するため、分散を拡大して識別力を維持
    """
    # 各軸のターゲット統計（ルールベース実績）
    TARGET_STATS = {
        "記憶性": {"mean": 6.24, "std": 0.35},
        "共感性": {"mean": 5.52, "std": 0.61},
        "意外性": {"mean": 5.45, "std": 0.52},
        "生成品質": {"mean": 8.46, "std": 0.56},
        "教育的価値": {"mean": 5.55, "std": 0.52},
        "ストーリー品質": {"mean": 6.70, "std": 0.45},
        "事実密度": {"mean": 9.57, "std": 1.05},
    }

    # LLMの想定分布（観測値ベース）
    LLM_STATS = {
        "mean": 7.5,
        "std": 0.3,  # LLMは分散が小さい
    }

    target = TARGET_STATS.get(axis, {"mean": 7.0, "std": 0.5})

    # Z-score正規化 → ターゲット分布に変換
    z_score = (llm_score - LLM_STATS["mean"]) / LLM_STATS["std"]
    calibrated = target["mean"] + z_score * target["std"]

    return max(1, min(10, round(calibrated, 1)))
```

### 2.3 Phase 7C: 動的重み調整

エピソードの特性に応じて重みを動的調整:

```python
def get_dynamic_weights(episode_data: Dict) -> Dict[str, Tuple[float, float]]:
    """
    エピソード特性に応じた動的重み決定

    - 数値・年号が多い → 事実密度はルール重視
    - 感情表現が多い → 共感性はLLM重視
    - 対話・引用が多い → ストーリー品質はLLM重視
    """
    episode_text = episode_data.get("episode_text", "")

    # 特性検出
    has_numbers = len(re.findall(r'\d+', episode_text)) > 5
    has_emotions = any(kw in episode_text for kw in ["涙", "感動", "喜び", "悲しみ"])
    has_dialogue = "「" in episode_text and "」" in episode_text

    weights = HYBRID_WEIGHTS.copy()

    if has_numbers:
        weights["事実密度"] = (1.0, 0.0)  # ルール100%

    if has_emotions:
        weights["共感性"] = (0.1, 0.9)  # LLM90%

    if has_dialogue:
        weights["ストーリー品質"] = (0.3, 0.7)  # LLM70%

    return weights
```
