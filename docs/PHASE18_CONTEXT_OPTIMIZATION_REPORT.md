### 1. コンテキスト使用状況の分析

#### 最適化前（2025-11-21 09:00）

```
Total: 200k tokens
- System prompt:    3.2k (1.6%)
- System tools:    14.9k (7.4%)
- MCP tools:       30.8k (15.4%) ← 削減ターゲット

- Memory files:    22.9k (11.4%)
```

#### 問題点の特定

- **MCP tools**: 30.8kが最大のボトルネック
  - playwright: 13.8k（38個のツール）
  - firecrawl: 9.2k（6個のツール）
  - brave-search: 4.1k（5個のツール）
  - fetch: 0.8k（1個のツール）

- **使用頻度**: これらのMCPサーバーは低頻度使用
  - Web検索: 必要時のみ
  - スクレイピング: 特定タスクのみ
  - ブラウザ自動化: 開発・テスト時のみ

### 2. 最適化戦略の策定

#### 選択的無効化アプローチ

**無効化対象**:
1. playwright (13.8k) - ブラウザ自動化・テスト
2. firecrawl (9.2k) - 高度なWebスクレイピング
3. brave-search (4.1k) - Web・画像・ニュース・動画検索
4. fetch (0.8k) - Web取得

**有効維持**:
1. context7 (1.7k) - ライブラリドキュメント取得（必須）
2. ide (1.3k) - IDE統合（必須）

#### 実装方法の選択

| 方法 | メリット | デメリット | 採用 |
|------|---------|----------|------|
| `disabled: true`フラグ | 一時有効化が容易 | 公式サポートなし | ✅ |
| `claude mcp remove` | 公式サポート | 再インストール必要 | - |

**採用理由**: カスタム実装だが、柔軟性が高く運用しやすい

### 3. 実装詳細

#### 設定ファイル作成

**`.claude/claude_code_config.json`**:

```json
{
  "mcpServers": {
    "fetch": {
      "disabled": true
    },
    "brave-search": {
      "disabled": true
    },
    "firecrawl": {
      "disabled": true
    },
    "playwright": {
      "disabled": true
    }
  }
}
```

**重要な注意事項**:
- `disabled`フラグはカスタム実装（公式サポートなし）
- 将来のClaude Codeバージョンで動作変更の可能性
- 公式方法: `claude mcp remove <server-name>`

#### スラッシュコマンド作成

**`.claude/commands/enable-web.md`**:

```markdown
# Web機能の一時的有効化

以下の手順で、Web検索・スクレイピング機能を一時的に有効化できます：

## 手順

1. `.claude/claude_code_config.json`を開く
2. 必要なサーバーの`disabled: true`を削除または`false`に変更
   - `brave-search` - Web検索
   - `firecrawl` - スクレイピング
   - `playwright` - ブラウザ自動化
   - `fetch` - Web取得
3. Claude Codeを再起動

## 使用後

作業完了後は、必ず`disabled: true`に戻してコンテキストを節約してください。
```

## 🔧 技術的詳細

### カスタム実装について

**`disabled: true`フラグの仕組み**:

```json
{
  "mcpServers": {
    "server-name": {
      "disabled": true  // カスタムフラグ
    }
  }
}
```

**注意事項**:
- Claude Code公式サポートではない
- 設定ファイルに明示的な警告コメントを追加
- 代替方法（`claude mcp remove`）も記載

### 再起動の必要性

**理由**:
- Claude Codeは起動時に設定ファイルを読み込む
- MCPサーバーの接続は起動時に確立
- 設定変更後は必ず再起動が必要

### トラブルシューティング

**効果が見られない場合**:

1. **設定ファイル確認**
   ```bash
   cat .claude/claude_code_config.json
   ```

2. **MCPサーバーリスト確認**
   ```bash
   claude mcp list
   ```

3. **代替方法（完全削除）**
   ```bash
   claude mcp remove fetch
   claude mcp remove brave-search
   claude mcp remove firecrawl
   claude mcp remove playwright
   ```
