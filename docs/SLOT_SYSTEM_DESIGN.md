# スロットシステム設計書

## 📋 概要

エピソードデータベースにおける`slot`フィールドの定義と割り当てロジックの設計書。

生成日時: 2025-11-25

---

## 🎯 目的

各人物の生涯エピソードを7つの年齢カテゴリ（スロット）に分類し、人生の重要な瞬間を効率的に表示・検索するためのシステム。

---

## 📊 スロット値の定義

### 基本スロット（7つの固定年齢カテゴリ）

| スロット値 | 年齢カテゴリ | 対象年齢範囲 | 説明 |
|-----------|-------------|-------------|------|
| **1** | 幼少期 | 0-5歳 | 誕生、幼少期の出来事 |
| **10** | 少年・少女期 | 6-15歳 | 学童期、才能の萌芽 |
| **20** | 青年期 | 16-25歳 | デビュー、キャリアスタート |
| **30** | 壮年期前期 | 26-35歳 | 実力発揮、飛躍期 |
| **40** | 壮年期後期 | 36-45歳 | 円熟期、リーダーシップ |
| **50** | 成熟期 | 46-55歳 | 経験活用、後進育成 |
| **60** | 晩年期 | 56歳以上 | 功績確立、集大成 |

## 🔧 割り当てロジック

### 方式1: 年齢ベース割り当て（シンプル）

各エピソードの実年齢に基づいて、最も近いスロットを割り当てる。

#### アルゴリズム

```python
def assign_slot_by_age(age: float) -> int:
    """実年齢から最も近いスロット値を返す"""
    slots = [1, 10, 20, 30, 40, 50, 60]

    if pd.isna(age):
        return None

    # 最も近いスロットを探す
    return min(slots, key=lambda slot: abs(age - slot))
```

#### 割り当て例

| 実年齢 | スロット | 理由 |
|-------|---------|------|
| 3歳 | 1 | 0-5歳の範囲 |
| 12歳 | 10 | 6-15歳の範囲 |
| 21歳 | 20 | 16-25歳の範囲 |
| 27歳 | 30 | 26-35歳の範囲 |
| 44歳 | 40 | 36-45歳の範囲 |
| 52歳 | 50 | 46-55歳の範囲 |
| 65歳 | 60 | 56歳以上 |

### 方式2: 重要度ベース割り当て（高度）

各人物の全エピソードを評価し、最も重要な7つを選定してスロットに割り当てる。

#### プロセス

1. **全エピソード評価**: 各エピソードの重要度スコアを計算
   - `episode_importance_score` (既存フィールド)
   - global_significance（世界的重要度）
   - historical_value（歴史的価値）
   - social_influence（社会的影響力）
   - career_importance（キャリア重要性）

2. **TOP7選定**: 各人物につき重要度上位7エピソードを選定

3. **スロット配置**:
   - **完全一致優先**: 実年齢がスロット年齢と一致 → そのまま配置
   - **最近接配置**: 最も近い空きスロットに配置
   - その他のエピソード: `slot = NULL` または `slot = 0`

#### メリット・デメリット

| 方式 | メリット | デメリット |
|------|---------|-----------|
| **年齢ベース** | シンプル、全エピソードにスロット割り当て可能 | 重要度を考慮しない |
| **重要度ベース** | 本当に重要なエピソードのみ選定 | 複雑、各人物の全エピソードが必要 |

---

## 🎨 推奨実装方式

### ハイブリッド方式（両方のメリットを活用）

1. **基本スロット**: 全エピソードに年齢ベースでスロットを割り当て（1-60）
2. **ハイライトフラグ**: 重要度TOP7エピソードに `is_highlight = True` フラグを設定

#### データベーススキーマ

```sql
ALTER TABLE episodes ADD COLUMN slot INTEGER;
ALTER TABLE episodes ADD COLUMN is_highlight BOOLEAN DEFAULT FALSE;
ALTER TABLE episodes ADD COLUMN slot_assignment_method VARCHAR(20);
```

#### スロット値の意味

- **slot = 1, 10, 20, 30, 40, 50, 60**: 年齢カテゴリ
- **is_highlight = True**: このエピソードは人物の生涯TOP7に選ばれた
- **slot_assignment_method**:
  - `"age_based"`: 年齢ベースで自動割り当て
  - `"importance_based"`: 重要度ベースで選定
  - `"manual"`: 手動設定

**A**: Yes（Phase 1で実装）
- 理由: 検索・フィルタリングの利便性向上

### Q2: 重要度ベース選定はいつ実装すべきか？

**A**: Phase 2（将来実装）
- 理由: より高度な機能、`lifetime_highlight_selector.py`の統合が必要
- 優先度: 中（基本スロットシステム確立後）

### Q3: スロット値はどのように使用されるか？

**A**: 以下の用途で使用
1. **年齢カテゴリフィルタ**: UIで「20代のエピソード」を表示
2. **生涯ハイライト**: 各人物の代表的な7つの瞬間を表示
3. **レコメンデーション**: ユーザーの年齢に近いエピソードを推薦
4. **統計分析**: 年齢カテゴリ別のエピソード分布分析
