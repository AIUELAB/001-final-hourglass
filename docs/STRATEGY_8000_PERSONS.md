## 3. 知名度スコアリング基準

### 3.1 スコア定義

```
知名度スコア = (認知率 × 0.4) + (検索量 × 0.3) + (メディア露出 × 0.2) + (歴史的重要性 × 0.1)
```

| スコア | ランク | 基準 | 例 |
|--------|--------|------|-----|
| 90-100 | S | 国民的知名度 | 大谷翔平、羽生結弦 |
| 70-89 | A | 高知名度 | 各分野トップ層 |
| 50-69 | B | 中知名度 | 業界著名人 |
| 30-49 | C | 限定知名度 | 世代・地域限定 |
| 0-29 | D | 低知名度 | 対象外 |

### 3.2 採用基準

- **必須採用**: スコア 70以上
- **優先採用**: スコア 50-69 かつ 教訓性あり
- **検討採用**: スコア 30-49 かつ 特定カテゴリ補完必要
- **対象外**: スコア 30未満

## 4. 犯罪者・センシティブ人物ポリシー

### 4.1 採用基準

| 条件 | 採用可否 | 理由 |
|------|----------|------|
| 社会的教訓が明確 | ○ | 歴史から学ぶ価値 |
| 被害者への配慮可能 | ○ | 実名回避・抽象化 |
| 模倣犯罪リスク | × | 手口詳細は記載しない |
| 現在進行形の事件 | × | 司法判断前は対象外 |

### 4.2 記載ルール

```
【犯罪者エピソードの記載ルール】

1. 犯行手口の詳細は記載しない
2. 被害者名は原則記載しない（著名人除く）
3. 教訓・社会的影響にフォーカス
4. 「～と同じ年齢のとき」形式で人生の分岐点を示す
5. 更生事例は積極的に取り上げる

【適切な例】
「あなたと同じ14歳のとき、◯◯は周囲との断絶から
取り返しのつかない過ちを犯した。この事件は少年法
改正の契機となり、社会全体で若者の孤立防止を
考えるきっかけとなった」

【不適切な例】
「あなたと同じ14歳のとき、◯◯は○○という手法で
○○を行った。具体的には...」
```

### 4.3 対象候補（教訓性重視）

| 人物/事件 | 教訓テーマ | 採用判定 |
|-----------|-----------|----------|
| 酒鬼薔薇聖斗 | 少年犯罪・孤立 | 要検討（匿名化） |
| 宮崎勤 | 精神医療・偏見 | 要検討 |
| 麻原彰晃 | カルト・洗脳 | 採用可（歴史的） |

## 5. LLM+EPUP エピソード生成フロー

### 5.1 7ステップEPUPプロセス

```
Step 1: 原因究明
├─ 既存エピソードの品質分析
├─ 低品質パターンの特定
└─ カテゴリ別の課題抽出

Step 2: システム修正
├─ プロンプトテンプレート改善
├─ 品質チェックロジック強化
└─ カテゴリ別ガイドライン追加

Step 3: 個別訂正
├─ 低品質エピソードの再生成
├─ 事実誤認の修正
└─ フォーマット統一

Step 4: 類似探索
├─ 同一人物の他エピソード確認
├─ 同カテゴリの品質比較
└─ パターン類似性検出

Step 5: 一括修正
├─ バッチ処理による大量改善
├─ カテゴリ単位の品質向上
└─ 自動品質ゲートチェック

Step 6: 予防設計
├─ 生成時の品質保証ルール
├─ カテゴリ別テンプレート
└─ 禁止表現リスト

Step 7: 継続的監視
├─ 定期品質レポート
├─ 異常値検出アラート
└─ 改善トレンド追跡
```

### 5.2 新規人物追加パイプライン

```
[候補収集] → [知名度判定] → [カテゴリ分類] → [エピソード生成] → [品質検証] → [DB登録]
     ↓              ↓              ↓              ↓              ↓
  Wikipedia     スコア50+      自動分類       LLM生成      EPUP検証
  公式リスト    手動確認       手動修正      テンプレート   意外性>=5.0
```

### 5.3 品質ゲート

| ゲート | 基準 | 不合格時の処理 |
|--------|------|----------------|
| 形式チェック | 「あなたと同じ」形式 | 自動修正 |
| 長さチェック | 80-200文字 | 再生成 |
| 意外性スコア | >= 5.0 | LLM再生成 |
| 事実整合性 | メタ表現なし | フラグ付け |
| 重複チェック | 類似度 < 0.8 | マージ検討 |
