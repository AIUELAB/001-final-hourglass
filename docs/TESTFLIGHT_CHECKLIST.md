# TestFlight 検証チェックリスト

## 基本動作

- [ ] アプリがクラッシュなく起動する
- [ ] オンボーディング画面が正しく表示される（初回起動時）
- [ ] オンボーディング全16ステップを完了できる
- [ ] オンボーディング完了後、メイン画面に遷移する

## 5タブ遷移

- [ ] タイムリミットタブ: 砂時計アニメーションが表示される
- [ ] タイムリミットタブ: 残り時間と死亡予定日が表示される
- [ ] タイムリミットタブ: エピソードが読み込まれる
- [ ] お気に入りタブ: エピソード一覧 or 空状態メッセージが表示される
- [ ] プロフィールタブ: ユーザーデータが正しく表示される
- [ ] 設定タブ: 各設定項目が操作できる
- [ ] Aboutタブ: アプリ情報が正しく表示される

## コア機能

- [ ] 砂時計のアニメーションが滑らかに動作する
- [ ] エピソードをお気に入りに追加・削除できる
- [ ] プロフィールの編集と保存ができる
- [ ] リマインダー通知のON/OFF切替ができる
- [ ] BGM・効果音の再生と音量調整ができる
- [ ] キャッシュクリアが正常に動作する
- [ ] データリセットが確認ダイアログ付きで動作する

## プライバシー・リンク

- [ ] プライバシーポリシーURL (`https://aiuelab.com/privacy`) が開く
- [ ] サポートURL (`https://aiuelab.com/support`) が開く
- [ ] 利用規約ページが表示される

## 表示・レイアウト

### ダークモード / ライトモード
- [ ] ダークモードで全画面が正しく表示される
- [ ] ライトモードで全画面が正しく表示される
- [ ] モード切替時にクラッシュしない

### iPad レイアウト
- [ ] iPadでタブバーが画面下部に表示される（サイドバーにならない）
- [ ] iPad横向きでレイアウトが崩れない
- [ ] iPad縦向きでレイアウトが崩れない
- [ ] Split Viewで表示が崩れない

### iPhone レイアウト
- [ ] iPhone SE（小画面）で表示が崩れない
- [ ] iPhone 16 Pro Max（大画面）で表示が崩れない
- [ ] 横向きでレイアウトが崩れない

## パフォーマンス

- [ ] アプリ起動が3秒以内に完了する
- [ ] タブ切替がスムーズである（ラグなし）
- [ ] エピソード読み込みが5秒以内に完了する
- [ ] メモリ使用量が異常に増加しない

## エッジケース

- [ ] ネットワークオフライン時にクラッシュしない
- [ ] バックグラウンドから復帰時にクラッシュしない
- [ ] 通知権限を拒否した場合もクラッシュしない
