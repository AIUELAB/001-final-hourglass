## システムの特徴

### 1. Fail-Fast原則
- エラーを隠蔽せず即座に顕在化
- ダミーデータでの処理継続を完全防止
- 品質基準未達時の即座停止

### 2. 多層防御
- 6層の独立したチェック機構
- 各層で異なる観点から検証
- 問題の早期発見と修正

### 3. 自動改善
- 事実データベースからの自動補完
- 定型文の自動置換
- 文字数の自動調整

### 4. PDCA Guardian準拠
- RULE_164（日付ノイズ禁止）完全対応
- 文字数制限（132-250文字）厳守
- 客観的事実のみ使用

## 使用方法

```python
from episode_quality_system.episode_factory import EpisodeFactory, EpisodeRequest

# システム初期化
factory = EpisodeFactory()

# エピソード生成リクエスト
request = EpisodeRequest(
    person_name="大谷翔平",
    age=30
)

# 高品質エピソード生成
response = factory.generate_episode(request)

print(f"エピソード: {response.episode}")
print(f"品質スコア: {response.quality_score}/100")
```
