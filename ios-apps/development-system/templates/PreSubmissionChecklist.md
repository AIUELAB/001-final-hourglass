# App Store 提出前チェックリスト

## 提出前最終確認 (必須項目)

### 1. アプリ基本情報

#### App Store Connect設定
- [ ] **アプリ名**: 30文字以内、既存アプリと重複なし
- [ ] **サブタイトル**: 30文字以内、キーワード含有
- [ ] **カテゴリー**: Primary/Secondary適切に設定
- [ ] **価格設定**: 価格層設定、地域別価格確認
- [ ] **可用性**: リリース地域・日時の設定

#### バージョン情報
- [ ] **バージョン番号**: セマンティックバージョニング（例: 1.0.0）
- [ ] **ビルド番号**: 前回より大きい整数値
- [ ] **新機能情報**: 今回のアップデート内容（4000文字以内）
- [ ] **修正内容**: バグ修正詳細（該当する場合）

### 2. メタデータ検証

#### アプリ説明文
- [ ] **説明文**: 4000文字以内、機能を明確に説明
- [ ] **キーワード**: 100文字以内、検索最適化
- [ ] **プロモーションテキスト**: 170文字以内（変更可能）
- [ ] **What's New**: アップデート内容の説明

#### 説明文チェックポイント
```markdown
**良い例**:
「写真を美しく編集できるアプリです。50種類以上のフィルターと直感的な操作で、誰でも簡単にプロ級の写真編集が可能です。」

**悪い例**:
「最高のアプリ！絶対ダウンロードすべき！他のアプリより優れています！」

**禁止表現**:
- "最高の"、"No.1"等の最上級表現（根拠がない場合）
- 他社製品の名前
- 価格に関する言及（「無料」等）
- Apple製品名の不適切な使用
```

### 3. スクリーンショット要件

#### iPhone用スクリーンショット
- [ ] **6.7インチ**: iPhone 14 Pro Max（1290 x 2796 px）[必須]
- [ ] **6.1インチ**: iPhone 14/iPhone 14 Pro（1170 x 2532 px）
- [ ] **5.5インチ**: iPhone 8 Plus（1242 x 2208 px）[必須]

#### iPad用スクリーンショット（iPadアプリの場合）
- [ ] **12.9インチ**: iPad Pro（2048 x 2732 px）[必須]
- [ ] **11インチ**: iPad Pro（1668 x 2388 px）

#### スクリーンショット品質基準
- [ ] **解像度**: 各デバイスの正確なピクセル数
- [ ] **向き**: 縦向き推奨（横向きの場合は統一）
- [ ] **枚数**: 最大10枚、最小1枚
- [ ] **順序**: 最も重要な機能を最初に表示
- [ ] **品質**: ぼやけなし、適切な明度・コントラスト

#### スクリーンショットNG例
```markdown
❌ 避けるべき内容:
- テスト用のデータや Lorem ipsum テキスト
- デバイスのステータスバーに問題（バッテリー残量1%等）
- 他社製品やブランドロゴの表示
- 不適切な内容やエラー画面
- 低解像度や圧縮による劣化
```

### 4. アプリアイコン検証

#### 技術要件
- [ ] **サイズ**: 1024 x 1024 px（App Store用）
- [ ] **フォーマット**: PNG形式（透明度なし）
- [ ] **カラープロファイル**: sRGB
- [ ] **角丸**: システムが自動適用（角丸を入れない）

#### デザインガイドライン準拠
- [ ] **視認性**: 小さいサイズでも判別可能
- [ ] **一貫性**: アプリ内アイコンとの統一感
- [ ] **独自性**: 既存アプリとの差別化
- [ ] **Apple HIG準拠**: Human Interface Guidelines準拠

#### アイコン禁止事項
- [ ] ❌ Apple製品の画像使用
- [ ] ❌ システムアイコンの模倣
- [ ] ❌ 不適切な内容（暴力、性的内容等）
- [ ] ❌ アプリ名の直接的な表示

#### Safety (安全性) - Section 1
