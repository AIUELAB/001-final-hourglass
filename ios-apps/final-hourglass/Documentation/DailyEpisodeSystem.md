# 日めくりエピソードシステム

## 概要
毎日異なるエピソードを表示し、ユーザーの正確な年齢に基づいて偉人のエピソードを提供するシステムを実装しました。

## 実装内容

### 1. EpisodeManager.swift
- **場所**: `/Managers/EpisodeManager.swift`
- **機能**:
  - Firebase Firestoreからエピソードを取得
  - ユーザーの正確な年齢でマッチング
  - 表示済みエピソードの追跡
  - 日付が変わったら新しいエピソードを表示
  - オフライン用キャッシュ（最新10件）

### 2. LifeResultView.swift の更新
- Firebaseからエピソードを動的に取得
- ローディング表示を追加
- フォールバック機構（オフライン時はハードコードエピソード）

### 3. SettingsView.swift の更新
- データリセット時にエピソード履歴もクリア

## データ構造

### Episode モデル
```swift
struct Episode {
    let id: String
    let personName: String        // 偉人名（英語）
    let personNameJa: String?      // 偉人名（日本語）
    let episode: String           // エピソード本文
    let deathAge: Int?           // 死亡年齢
    let episodeType: String?     // エピソードタイプ
    let tags: [String]?          // タグ
}
```

### UserDefaults キー
- `viewedEpisodeIds`: 表示済みエピソードIDのリスト
- `lastEpisodeDate`: 最後にエピソードを見た日付
- `dailyEpisode`: 今日のエピソード（キャッシュ）
- `cachedEpisodes`: オフライン用キャッシュ

## エピソード取得ロジック

1. **日付チェック**: 新しい日かどうか確認
2. **年齢マッチング**:
   - まず正確な年齢で検索
   - なければ±1歳、±2歳...と範囲を拡大
   - 最大±10歳まで検索
3. **重複回避**: 表示済みIDを記録して重複を防ぐ
4. **フォールバック**:
   - Firebaseから取得できない場合はキャッシュから
   - キャッシュもない場合はハードコードエピソード

## 現在の制限事項

### エピソード数の不足
- **必要数**: 36,500件（100歳 × 365日）
- **現在数**: 6,202件（約17%）
- **対策**:
  - 表示済みエピソードの再利用（30日後）
  - 年齢範囲を広げて検索
  - オフラインキャッシュの活用

### 改善案
1. **エピソード追加生成**: 残り30,298件のエピソード生成が必要
2. **AI生成**: GPT-4を使用した大量生成
3. **カテゴリ別管理**: 年齢層別、テーマ別にエピソード管理
