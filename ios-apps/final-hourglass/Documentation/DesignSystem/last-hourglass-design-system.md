## 5. アニメーション原則

### タイミング
```
瞬間的: 100ms - マイクロインタラクション
標準: 300ms - 状態変化
ゆっくり: 2.5s - フェードイン
儀式的: 6s - 砂の流れ
永遠: 25-30s - 背景の動き
```

### 動きの性質
- **重力** - 砂や粒子は自然な物理法則に従う
- **浮遊** - 神秘的な要素は重力から解放される
- **循環** - 生と死のサイクルを表現
- **脈動** - 生命のリズムを感じさせる

## 10. アクセシビリティ

### コントラスト比
- 大きなテキスト: 3:1以上
- 通常のテキスト: 4.5:1以上
- 重要な要素には追加の視覚的手がかり

### モーション配慮
- prefers-reduced-motionに対応
- 重要な情報はアニメーションに依存しない
- 一時停止可能なアニメーション

## 11. 実装ガイドライン

### 命名規則
```
.mystical-[要素名]  // 神秘的な要素
.stained-glass-[要素名]  // ステンドグラス風
.divine-[要素名]  // 聖なる要素
```

### パフォーマンス最適化
- アニメーションにはGPU加速を使用
- 複雑なエフェクトは`will-change`で最適化
- 画像アセットは適切に圧縮

## 12. ブランドボイス

### トーン
- **詩的** - 「その一粒が落ちる日を知る覚悟はありますか」
- **哲学的** - 深い問いかけ
- **荘厳** - 敬意を持った語りかけ

### 言葉遣い
- 敬語は使わず、詩的な表現を優先
- 死を直接的に表現せず、比喩を使用
- 希望を完全に断たない配慮

## 13. 使用例

### 画面構成の基本パターン
1. 深い背景に神秘的なエフェクト
2. 中央に象徴的なビジュアル要素
3. 詩的な問いかけ
4. 明確な行動への誘導
5. 控えめなブランド表示

### 禁止事項
- 明るすぎる色の使用
- 軽薄な表現やカジュアルすぎるトーン
- 過度にリアルな死の描写
- 宗教的シンボルの直接的使用
