# サウンド演出実装ガイド

## 実装完了内容

### 🎵 追加したサウンド効果

1. **扉が開く音**
   - タイミング: 画面遷移開始時
   - サウンド: アンロック音 + 通知チャイム
   - 触覚: Heavy（重厚感）

2. **砂時計出現音**
   - タイミング: 砂時計表示時（1秒後）
   - サウンド: メール送信完了音
   - 触覚: Soft（やさしい感触）

3. **カウントアップ音**
   - タイミング: 残り時間表示時
   - サウンド: キーボードタップ音の連続
   - 完了音: 支払い成功音
   - 触覚: なし（音のみ）

4. **死亡予定日表示音**
   - タイミング: 死亡予定日表示時（3.5秒後）
   - サウンド: カメラシャッター音 + エコー効果
   - 触覚: Heavy（インパクト大）

5. **いいねタップ音**
   - タイミング: いいねボタンタップ時
   - サウンド: Tink音（軽快）
   - 触覚: Light（軽いフィードバック）

### 🔊 使用したシステムサウンド

```swift
// iOS内蔵サウンドID
keyboardTap = 1104      // カウントアップ
tink = 1057            // いいねタップ
cameraShutter = 1108   // 決定音
unlock = 1101          // 扉開放音
mailSent = 1001        // 砂時計出現
notificationChime = 1312 // 追加効果音
```

### ⚙️ 設定管理

```swift
@AppStorage("soundEnabled") // サウンドON/OFF
@AppStorage("soundVolume")  // 音量（将来用）
@AppStorage("hapticEnabled") // 振動ON/OFF
```

### 🎯 演出タイミング

```
0.0秒: 扉が開く音
1.0秒: 砂時計出現音
2.5秒: カウントアップ音（10回）
3.5秒: 死亡予定日表示音（+エコー）
任意: いいねタップ音
```

### 📱 触覚フィードバック

- **Heavy**: 扉、死亡予定日（重要な瞬間）
- **Medium**: 通常のタップ
- **Light**: いいねボタン
- **Soft**: 砂時計出現（やさしい演出）

### 🔧 カスタマイズ方法

```swift
// 新しい音を追加
SoundManager.shared.playSystemSound(.newSound)

// カスタムシーケンス
SoundManager.shared.playCountUpSequence(
    count: 20,
    interval: 0.05
)

// 触覚のみ
SoundManager.shared.playHaptic(.heavy)
```

### 🎮 ユーザー設定

設定画面から以下が可能：
- サウンド効果のON/OFF
- 振動フィードバックのON/OFF
- デフォルトは両方ON
