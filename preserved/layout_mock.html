✨ メリット

  • テーブル幅が劇的に削減される（14カラム → 7カラム = 50%削減）
  • 識別情報が1箇所にまとまり視認性向上 - エピソードID、パーソナルID、人物名が縦3行で見やすく
  • 基本情報が1箇所にまとまり効率的 - 年齢、スロット、エピソード数が縦3行で見やすく
  • 有名度系が1箇所にまとまり比較しやすい - 有名度とエピ有名度が縦2行で見やすく
  • 分類情報が1箇所にまとまり整理される - カテゴリ、実在/架空、作品が縦3行で見やすく
  • ラベル付きで各項目の意味が明確 - すべての項目にラベルが付き、直感的に理解可能
  • 水平スクロールがほぼ不要 - 全カラムを表示しても画面内に収まりやすい
  • ソート機能は維持 - 各項目でソート可能
  • データの構造が明確 - 関連情報がグループ化され、一目瞭然
📊 カラム構成: 識別情報(3行) + 基本情報(3行) + 有名度系(2行) + 総合 + 分類情報(3行) + 文字数 + エピソード全文 = 7カラム
📝 注意: ソート機能は引き続き全項目で利用可能（Episode ID, Person ID, 人物名, 年齢, スロット, エピソード数, 有名度, エピ有名度, 総合, カテゴリ, 実在/架空, 作品, 文字数）
