## 2. システム概要

### 2.1 アーキテクチャ

```
┌─────────────────────────────────────────────────────┐
│  入力: 人物名、カテゴリ、年齢                        │
│                                                      │
│  [1] 品質重視プロンプトで初稿生成                    │
│       ↓                                             │
│  [2] LLM自己評価（7軸採点）                         │
│       ↓                                             │
│  [3] 品質ゲートチェック                             │
│       ├─ 超総合 >= 550 → 即採用 ✅                  │
│       ├─ 超総合 <  400 → 即棄却 ❌                  │
│       └─ 400-549 → 弱軸特定 → 改稿 → 再評価        │
│                                                      │
│  出力: 高品質エピソード + 7軸スコア                  │
└─────────────────────────────────────────────────────┘
```

### 2.2 品質ゲート設定

```python
QUALITY_GATES = {
    "minimum_composite": 400,    # 即棄却ライン
    "target_composite": 550,     # 即採用ライン
    "retry_threshold": 480,      # リトライ後採用ライン
    "max_retries": 1,            # 最大リトライ回数
}
```

### 2.3 弱軸改善プロンプト

弱い軸（スコア4.5未満）を検出し、軸別の改善指示を自動付与：

- **共感性**: 感情描写、内面の葛藤、普遍的状況の追加
- **意外性**: 予想外の展開、常識を覆す視点の追加
- **教育的価値**: 具体的教訓、普遍的知恵の追加
- **事実密度**: 年号、数値、固有名詞の追加

## 4. 注意点・制限事項

### 4.1 LLM自己評価の信頼性

- LLMは自己評価で甘めに採点する傾向がある
- 人間によるサンプリング検証が推奨される
- 定期的に人間評価との相関を確認すべき

### 4.2 サンプルサイズ

- 今回のテストは5件のみ
- 本格運用前に50-100件規模でのテストを推奨

## 5. 運用ガイド

### 5.1 基本的な使い方

```bash
# テスト実行（10件、保存なし）
python scripts/generate_with_quality_gate.py --count 10 --dry-run

# 本番実行（50件）
python scripts/generate_with_quality_gate.py --count 50 --execute

# 特定年齢で生成
python scripts/generate_with_quality_gate.py --count 30 --ages 25,30,35 --execute
```

### 5.2 品質ゲート調整

`scripts/generate_with_quality_gate.py` 内の `QUALITY_GATES` を調整：

```python
# より厳格に（S評価狙い）

QUALITY_GATES["retry_threshold"] = 600

# より緩やかに（量産重視）
QUALITY_GATES["target_composite"] = 500
QUALITY_GATES["minimum_composite"] = 350
```
