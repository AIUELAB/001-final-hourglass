## 🔧 実装方法

### 1. エピソード生成スクリプトの活用

既存のスクリプトを活用:
- `scripts/generate_episodes_with_llm.py`
- カテゴリとperson_nameを指定して生成

### 2. テンプレート作成

不足カテゴリ用のテンプレートCSV作成:
```csv
person_name,category,age,person_type
黒澤明,映画・演劇,48,REAL
小津安二郎,映画・演劇,57,REAL
...
```

### 3. バッチ生成

カテゴリごとに一括生成:
```bash
python3 scripts/generate_episodes_with_llm.py \
  --template templates/film_theater_batch1.csv \
  --output film_theater_batch1_episodes.csv \
  --limit 30
```

### 4. 品質チェックと統合

生成後、品質チェック:
- composite_score >= 80を確認
- 重複チェック
- MASTER_EPISODES_CURRENT.csvに統合
