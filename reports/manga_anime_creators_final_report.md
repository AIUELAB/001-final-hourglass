**背景**: 日本のポップカルチャーを世界に広めた漫画家・アニメクリエイターを独立したカテゴリとして分類。

**実装**:
```python
# award_levelが空の場合に"MANGA_ANIME"を設定
if not row_dict.get("award_level", "") or row_dict.get("award_level", "").strip() == "":
    row_dict["award_level"] = "MANGA_ANIME"
```
