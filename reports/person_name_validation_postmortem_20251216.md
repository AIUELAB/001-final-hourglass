## 3. 原因調査（意図的 or 事故）

### 結論: **事故による誤混入**

### 証拠

#### A. 生成プロンプト分析

`scripts/generate_senior_episodes.py` (Line 265-266) を確認：

```python
# 1. 「あなたと同じ{age}歳のとき、{person_name}は〜」という形式で始める
```

**発見**: プロンプトには役職語・関係語を追加する指示は一切なし。`{person_name}` 変数をそのまま使用。

#### B. テンプレートデータ分析

- `templates/phase52_politics.csv` に「岸田文雄」（本人）は存在
- 「岸田文雄夫人」「サンダース上院議員」は**テンプレートに含まれていない**
- `templates/phase8_senior_batch1_with_birthyear.csv` にも含まれていない

#### C. エピソード本文の矛盾

**岸田文雄夫人のエピソード本文** (EP-000006050):
```
あなたと同じ55歳のとき、岸田文雄夫人の岸田裕子さんは2021年、...
```
→ LLMが「岸田文雄夫人」という person_name を受け取り、本文で「岸田裕子さん」と補足している

**サンダース上院議員のエピソード本文** (EP-000005313):
```
あなたと同じ70歳のとき、サンダース上院議員は2012年の上院選で...
```
→ フルネーム（バーニー・サンダース）が一切含まれていない

#### D. 最古バックアップでの確認

`data/backups/MASTER_pre_group_fix_20251202_171354.csv` (2024年12月2日):
- 既に「サンダース上院議員」「岸田文雄夫人」として記録されていた
- **生成時点から既にその名前だった**

### 推定原因

**エピソード生成時に使用されたテンプレートCSVまたは手動追加時に誤った person_name が記入された**

- `generate_senior_episodes.py` はテンプレートの person_name カラムをそのまま使用 (Line 117)
- テンプレートには正規表記（岸田文雄）が存在していたが、別のバッチまたは手動追加時に誤記入

---

## 4. 対応方針と実施済み施策

### 基本方針: **A. 純粋な人物名のみ**

person_name には以下を含めない：
- 役職語（上院議員、首相、大統領、社長、CEO等）
- 関係語（夫人、妻、夫、母、父等）
- 説明文・修飾語

### 例外ケース（許容）

| カテゴリ | 例 | 理由 |
|---------|-----|------|
| 歴史上の正式称号 | 明治天皇、昭和天皇、始皇帝 | 正式名称として確立 |
| 芸名 | DJ社長 | 公式芸名 |
| 宗教称号 | 教皇フランシスコ、ダライ・ラマ14世 | 公式称号 |

### 実施済み施策

#### 1. ALIAS_KEYWORDS 辞書への登録

**ファイル**: `scripts/normalize_person_names.py` (Line 204-205)

```python

    "山中教授": "山中伸弥",
    "マンデラ": "ネルソン・マンデラ",

    "Mackenyu": "新田真剣佑",
    "サンダース上院議員": "バーニー・サンダース上院議員",  # 追加

```

- `_check_org_title_contamination()`: 役職語検出

- ALIAS_KEYWORDS 辞書を参照して自動警告

#### 3. 日次KPI監視
