## 根本原因分析

### 1. 記憶性 <-> 生成品質（r=0.887）

**原因**: 両軸が同じ要素を評価している
- 記憶性: `fact_density` + LLM印象
- 生成品質: `text_quality` (ルール90%)

**根本原因**:
- テキスト品質が高い → 事実密度も高い傾向
- 両軸のルールベース計算が類似したパターンを検出

### 2. 共感性 <-> 意外性（r=0.803）

**原因**: LLMスコアへの依存度が同じ（両方70%）
- 共感性: `emotion_score` (30%) + LLM `empathy` (70%)
- 意外性: `turning_score` (30%) + LLM `surprise` (70%)

**根本原因**:
- ルールベースの感情・転機キーワードが重複
- LLM評価時に感情的要素が両方に影響

## 改善提案

### 即時実装可能（Phase 1）

#### 1.1 キーワードリストの差別化

**共感性キーワード**（感情・人間関係に特化）:
```python
EMPATHY_ONLY_KEYWORDS = [
    "涙", "感動", "喜び", "悲しみ", "苦悩", "希望",
    "家族", "母", "父", "子供", "友人", "恩師", "愛",
    "心", "思い", "気持ち", "願い", "祈り"
]
```

**意外性キーワード**（展開・事実に特化）:
```python
SURPRISE_ONLY_KEYWORDS = [
    "実は", "意外にも", "驚くべき", "予想外", "突然",
    "逆転", "番狂わせ", "史上初", "世界初", "前例のない",
    "秘密", "真実", "知られざる", "皮肉にも"
]
```

#### 1.2 重み調整による差別化

現在:
| 軸 | ルール | LLM |
|----|--------|-----|
| 共感性 | 30% | 70% |
| 意外性 | 30% | 70% |

提案:
| 軸 | ルール | LLM | 理由 |
|----|--------|-----|------|
| 共感性 | 20% | 80% | 感情はLLM向き |
| 意外性 | 50% | 50% | 事実確認はルール向き |

#### 1.3 記憶性の再定義

現在: `fact_density` ベース（生成品質と重複）

提案: 独自の記憶性要素を追加
```python
MEMORABILITY_UNIQUE_KEYWORDS = [
    "印象的", "忘れられない", "鮮明", "象徴的",
    "転換点", "分岐点", "決定的", "運命",
    "ドラマチック", "エポックメイキング"
]
```

### 中期改善（Phase 2）

#### 2.1 軸の統合検討

高相関ペアの統合オプション:
1. **記憶性 + 生成品質 → 総合品質** として1軸に
2. **共感性 + 意外性 → 感情インパクト** として1軸に

#### 2.2 新軸の追加

軸を減らす代わりに、独立性の高い新軸を検討:
- **具体性**: 数値・固有名詞の密度
- **普遍性**: 教訓の一般化度合い
- **独自性**: 他エピソードとの差別化度

### 長期改善（Phase 3）

#### 3.1 評価基準の再設計

7軸から5軸へ最適化:
1. **事実密度** (ルール100%): 客観的指標
2. **感情インパクト** (LLM80%): 共感性+意外性を統合
3. **教育的価値** (バランス): 教訓・学び
4. **ストーリー品質** (バランス): 構成・展開
5. **総合品質** (ルール70%): 記憶性+生成品質を統合
