# 同一出来事複数年齢出現検出 テスト観点表

## テスト対象
- `scripts/validation/duplicate_event_detection_gate.py`
- `scripts/validation/comprehensive_fact_checker.py`
- `scripts/validation/fix_hemingway_duplicate_events.py`

## テストケース一覧

| ID | カテゴリ | テストケース | 期待結果 | 優先度 |
|----|----------|--------------|----------|--------|
| T1 | 検出 | 同一人物で同一イベントが複数年齢に出現 | 検出される | 高 |
| T2 | 正常系 | 修正後のヘミングウェイは検出されない | 0件 | 高 |

| T7 | パターン | 受賞（ノーベル/ピューリッツァー/アカデミー）検出 | 正確に抽出 | 中 |

## テスト観点

### 1. 検出精度
- 同一イベントが複数年齢に出現 → 検出される
- 年齢差が10歳以上 → CRITICAL判定
- 年齢差が5-9歳 → HIGH判定
- 年齢差が2歳未満 → 検出されない（許容）

### 2. ヘミングウェイ修正確認
- 45歳エピソードに『老人と海』がない
- 61歳エピソードに『老人と海』がない
- 45歳と61歳で同一イベントの重複がない

### 3. ゲート動作
- CRITICAL > 0 → ゲート失敗（--info-only なしの場合）
- --info-only → ゲート通過（情報のみ）

### 4. 過検出防止
- 過去の経歴を参照する表現は許容する
- 例: 「X年に発表した作品が...」という言及
