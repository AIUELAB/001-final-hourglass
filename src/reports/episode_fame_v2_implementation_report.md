# Episode Fame Score v2 実装レポート

## 概要

**実装日**: 2025-12-26
**目的**: 「感銘を受けやすいエピソード」を上位にランキングするための新スコアリングシステム

---

## 1. v1の根本原因分析

### 問題1: 同一人物の独占
- v1 Top30のうち葛飾北斎18件（60%）、黒澤明8件（27%）
- 合計87%が2人だけで占有
- 独占制御機能がなかった

### 問題2: 「感銘」の評価不足
- 現行LLM 7軸: 記憶性/共感性/意外性/生成品質/教育的価値/ストーリー品質/事実密度
- 「困難克服」「努力」「決断」「社会的転機」が直接評価されていなかった

### 問題3: キーワードボーナスの不適切
- 「ノーベル賞」+8点は適切
- 「差別撤廃」「公民権運動」「社会変革」などが未対応

---

## 2. v2設計

### 計算式

```
episode_fame_v2 =
    InspirationScore × 0.40 +   # 感銘度（新規・最重要）
    QualityScore × 0.25 +        # 品質（LLM 7軸ベース）
    HistoricalImpact × 0.20 +    # 歴史的インパクト
    PersonFame × 0.15            # 人物知名度
```

### InspirationScore（感銘度）5軸

| 軸 | 重み | 内容 |
|---|------|------|
| difficulty | 25% | 困難度（逆境・苦難） |
| effort | 20% | 努力度（継続・訓練） |
| decision | 15% | 決断度（人生の転機） |
| achievement | 25% | 達成度（成功・受賞） |
| social_impact | 15% | 社会的影響（貢献） |

### 偏り制御（同一人物独占防止）

| 対象 | 制限 |
|------|------|
| Top100 | 同一人物最大3件 |
| Top50 | 同一人物最大2件 |
| Top20 | 同一人物最大1件 |

## 5. 今後の改善点

1. **キーワード辞書の拡充**: より多くの感銘パターンをカバー
2. **LLM評価の導入**: 感銘度をLLMで補助評価（キャッシュ付き）
3. **ペアワイズ評価**: 「どちらが感銘を受けるか」の比較データセット構築
4. **参考ランキング一致率の向上**: 現在35%を50%以上に

## 7. 結論

v2は「感銘を受けやすいエピソード」のランキングとして、v1の問題（同一人物独占、感銘評価不足）を大幅に改善した。ネルソン・マンデラ、ダライ・ラマ、マリー・キュリーなどの「困難→努力/決断→達成」パターンを持つエピソードが上位に来るようになった。

v1とv2は併存しており、比較・ロールバックが可能。
