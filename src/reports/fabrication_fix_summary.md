# 捏造エピソード問題 - 修正完了レポート

**日時**: 2026-01-03
**対応者**: Claude Code

## 📌 問題概要

ユーザーがEP-000001083（大谷翔平 63歳）のエピソードが完全な捏造であることを発見。
調査の結果、`regenerate_with_surprise.py`スクリプトが根本原因と特定。

### 問題の原因

`scripts/utils/regenerate_with_surprise.py` の設計欠陥:

1. **高temperature設定 (0.8)**: 創造性を促進し、事実から逸脱
2. **捏造誘発プロンプト**:
   - 「意外な出会いや偶然の発見」
   - 「常識に反する決断」
   - 「周囲の反対を押し切った行動」
3. **事実検証なし**: 生成後の事実確認が一切なかった

## 🔍 検出された問題

| カテゴリ | 件数 | 例 |
|---------|------|-----|
| 未来エピソード | 5件 | 大谷翔平63歳（2057年）、浅田真央63歳（2053年） |
| 死亡後エピソード | 2件 | 志村けん75歳（2025年、死亡2020年） |
| 埋め草エピソード | 40件 | 鳥山明48歳（具体的事実なし） |
| 捏造エピソード | 322件 | 「農業を始めた」「養蜂業」等の架空ストーリー |
| **合計** | **369件** | |

### 特に深刻な捏造例

- **EP-000001083**: 大谷翔平63歳「岩手県で農業を始めた」→ 2057年の架空未来
- **EP-000000168**: 浅田真央63歳「養蜂業を営んでいた」→ 2053年の架空未来
- **EP-000000181**: 志村けん75歳「AIとコラボレーション」→ 死亡後の不可能なエピソード

## ✅ 実施した修正

### 1. 問題エピソード削除

- **削除件数**: 369件
- **削除前**: 10,653件
- **削除後**: 10,284件
- **バックアップ**: `MASTER_EPISODES_CURRENT.csv.bak_purge_20260103_034445`

### 2. 根本原因の除去

```bash
rm scripts/utils/regenerate_with_surprise.py
```

このスクリプトは根本的に欠陥があるため完全削除。

### 3. 品質ゲート強化

#### 3.1 時間的妥当性検証の追加

`generate_with_quality_gate.py` に以下を追加:

```python
def validate_temporal_accuracy(person_name, age, person_type):
    """未来/死亡後エピソードを検出"""
    - 既知の人物の生年・没年をチェック
    - 死亡後のエピソード → 即却下
    - 未来のエピソード（現在+2年以上） → 即却下
```

#### 3.2 埋め草検出モジュール強化

`filler_detector.py` を強化:

- **抽象フレーズ追加**: 「続けていました」「行っていました」等の継続系パターン
- **捏造パターン追加**: 「養蜂業」「農業を始め」「周囲の猛反対を押し切」等
- **即却下ルール**: 捏造パターン検出で即却下

### 4. 作成した新ツール

- `scripts/validation/purge_fabricated_episodes.py`: 捏造エピソード一括検出・削除
- `scripts/validation/comprehensive_fact_checker.py`: 矛盾エピソード検出

## 📊 残存する SURPRISE_IMPROVED エピソード

902件の SURPRISE_IMPROVED ソースエピソードが残存していますが、これらは:

- 時間的妥当性検証をパス（未来/死亡後ではない）
- 捏造パターンを含まない
- 埋め草パターンが閾値未満

今後は `regenerate_with_surprise.py` が削除されたため、新たな捏造エピソードは生成されません。

## 🛡️ 再発防止策

1. **時間的妥当性チェック**: 生成時に必ず検証
2. **捏造パターン検出**: 生成時に即却下
3. **埋め草パターン検出**: 具体性スコアと抽象度をチェック
4. **problematic script削除**: 高temperature+創作プロンプトの禁止
