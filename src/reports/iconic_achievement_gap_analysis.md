# 象徴的業績欠落問題 - 根本原因分析レポート

## 発生日時
2026-01-06

## 発見された問題
大谷翔平のWBC優勝・MVP（2023年）など、人物の最も象徴的な業績がエピソードとしてカバーされていなかった。

## 根本原因

### 1. 年齢ベース生成ロジックの限界
```
現在のロジック: 人物 × 年齢 → エピソード生成
問題: 「何歳のエピソードを生成するか」は決まるが、
      「どの業績をカバーするか」は保証されない
```

### 2. ランダム選択による網羅性の欠如
- `pipeline_layer1_generate.py` は候補をランダム選択
- 重要な業績年齢が選ばれる保証がない
- 例: 大谷翔平28歳（WBC年）が選択されなかった

### 3. 業績マスターデータの不在
- 「この人物にはこの業績エピソードが必須」という定義がない
- 生成後に網羅性を検証する仕組みがない

### 4. 品質ゲートの不足
- format_check、meta_check は存在
- **achievement_coverage_check は存在しない**

## 影響範囲
- 大谷翔平: WBC、新人王、2回目MVP が欠落
- アインシュタイン: ノーベル賞受賞年エピソードが欠落
- 他の著名人物にも同様の問題がある可能性

## 再発防止策

### 即時対応
1. 象徴的業績マスターデータ作成
2. 業績カバレッジ監査ツール実装
3. EPUPルールへの追加

### 長期対応
1. 生成パイプラインに業績優先ロジック追加
2. 定期監査の自動化
3. 新規人物追加時の業績チェックリスト必須化
