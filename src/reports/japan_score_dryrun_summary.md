## 2. 計算式（承認済み）

```
if is_japanese:
    boost = base_alpha(10%) + category_weight + pv_ratio_bonus
    japan_score = global_score × (1 + boost)
else:
    japan_score = global_score

カテゴリ重み:
  スポーツ: +40%
  音楽: +20%
  エンターテイメント: +20%
  アニメ/漫画: +25%
  その他: +5%

PV比率ボーナス: min(ja_pv/total_pv × 0.5, 15%)
```
