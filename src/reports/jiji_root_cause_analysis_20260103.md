## 3. 根本原因の特定

### 3.1 直接原因（Why #1）
LLMが原作に存在しない内容を「創作」した。

### 3.2 なぜ創作が許可されたか（Why #2）
架空キャラ用プロンプト（fix_fictional_meta_episodes.py:113-117）に以下のルールがある：

```
【生成方針】
- 原作で{age}歳時点の描写があればそれを活用
- なければ、キャラクター設定から自然に導かれるエピソードを創作  ← これ
```

「創作」が明示的に許可されている。

### 3.3 なぜ30歳という年齢が割り当てられたか（Why #3）
- 架空キャラクターに対して、人間用の年齢範囲生成ロジックが適用された
- ジジ（猫）に明確な年齢設定はないが、機械的に「30歳」が割り当てられた

### 3.4 なぜ品質ゲートを通過したか（Why #4）
既存の品質ゲートは以下のみをチェック：
- メタ的説明（「架空のキャラクター」「エピソードは存在しません」等）
- 禁止フレーズ

以下はチェックされていない：
- カノン整合性
- 根拠なき年齢設定
- 一般的キャリア文（テンプレート的な内容）

### 3.5 根本原因（Why #5）
**架空キャラクターの品質定義が不完全**

- 「物語に存在する出来事のみ許可」というルールが欠如
- 「創作許可」が明示的にプロンプトに含まれている
- カノン検証の仕組みがない
