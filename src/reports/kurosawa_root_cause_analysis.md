# 黒澤明 年齢不整合 根本原因分析

## 発見された問題

### 1. 同一出来事の年齢乱立
『乱』完成/公開に関して15件のエピソードが存在し、年齢が70〜85歳と分散。
正しい年齢（75歳）のエピソードは存在しなかった。

### 2. エピソード数制限違反
黒澤明: 25件（person_nameベース）/ 44件（全文検索）
制限: 5件

## 根本原因

### 原因1: 年齢埋め草生成
- `scripts/generate/generate_episodes_by_age_range.py` による年代別生成
- 年齢範囲（30代/40代/...）ごとにエピソードを生成
- **問題**: 出来事の西暦年からの年齢逆算検証なし

### 原因2: 事実確認の欠如
- LLMが年齢を「推測」で生成
- 『乱』=1985年公開という事実が参照されていない
- 黒澤明生年（1910年）との照合なし

### 原因3: 重複検知の不備
- 同一人物×同一作品の重複チェックなし
- エピソード間の類似度比較なし

### 原因4: 人物別上限の未実装
- 「1人5件まで」のルールが品質ゲートに未実装

## 証拠

削除されたエピソードID（EP-251218185058xxx）:
- 日時パターン: 2024年12月18日 18:50:58に一括生成
- 年齢バリエーション: 70/71/72/73/74/76/77/78/79/80/81/82/83/84/85

## 修正完了

1. ✅ 黒澤明エピソード: 25件→5件に削減
2. ✅ 『乱』年齢: 70歳→75歳に修正
3. ✅ 『七人の侍』: 44歳で新規作成
4. ❌ 品質ゲート追加: 未実装（再発防止として必要）
