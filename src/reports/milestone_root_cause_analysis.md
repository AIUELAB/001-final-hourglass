# マイルストーン年齢不整合の根本原因分析

## 問題概要
同一人物の同一マイルストーン（例：尾崎豊のレコードデビュー）が複数の年齢で発生したように書かれていた。

## 根本原因候補（3つ以上）

### 原因1: バッチ生成による整合性欠如（確度: 高）
**根拠**:
- `scripts/add_iconic_episodes_batch3.py` に尾崎豊26歳（死去）のみが含まれる
- 他の年齢（14, 15, 16, 18歳）は別バッチで追加された可能性
- Git履歴に複数回のエピソード追加コミットが存在
- 異なる時期・異なるプロンプトで生成されたエピソード間で整合性チェックなし

**証拠**: `git log --oneline -- preserved/data/MASTER_EPISODES_CURRENT.csv` で複数回の修正履歴

### 原因2: 生成プロンプトの年齢コンテキスト不足（確度: 中）
**根拠**:
- 生成時に「この人物の他年齢エピソードでデビューが書かれているか」を確認していない
- LLMは各エピソードを独立して生成するため、cross-episode整合性が取れない
- `scripts/generate/generate_episodes_by_age_range.py` にマイルストーン整合性ロジックなし

**推測**: 生成プロンプトに「他年齢で既に書かれたイベントを重複させない」指示がなかった可能性

### 原因3: 事後検証ゲートの欠如（確度: 高）
**根拠**:
- `comprehensive_fact_checker.py` は存在するがKNOWN_FACTSは限定的
- マイルストーン重複を検出するゲートがEPUPパイプラインになかった
- 過去の修正履歴（ノーベル賞受賞年齢不整合22件等）も同種問題

**証拠**: 本タスクで `milestone_consistency_gate.py` を新規作成した

### 原因4: データマイグレーション時の品質劣化（確度: 低）
**根拠**:
- CSVの形式変更やマイグレーション時にテキストが変形した可能性
- ただし、尾崎豊のケースはテキスト内容が「年齢に合わせて書かれている」ため、意図的な生成の可能性が高い

## 結論
**主原因**: バッチ生成 + 事後検証ゲートの欠如

エピソードは複数のバッチ・異なるタイミングで独立生成されるが、
「同一人物の同一イベントが複数年齢で書かれていないか」を
検証するゲートがなかったため、不整合が混入し続けていた。

## 再発防止策（実装済み）
1. `scripts/validation/milestone_consistency_gate.py` - マイルストーン整合性ゲート
2. `scripts/validation/detect_milestone_age_conflicts.py` - 全体スキャン
3. `tests/test_milestone_consistency.py` - 回帰テスト（14件）
4. `comprehensive_fact_checker.py` の KNOWN_FACTS にデビュー年齢を登録

## 追加で必要な情報（未確定の場合）
- 各エピソードの `generation_timestamp` を確認し、同一人物の複数エピソードが
  異なるタイミングで生成されたことを証明する
- 生成時のプロンプトログがあれば、マイルストーン指示の有無を確認
