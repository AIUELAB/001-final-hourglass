## 2. 各バージョンの問題点

### 2.1 v1 (episode_fame_score) の問題

**実装箇所**: `scripts/score/calculate_episode_fame.py:17-74`

**計算式**:
```python
score = 50.0  # ベーススコア
# エピソードタイプボーナス (+5〜+15)
# 超有名キーワード (+10, 事実密度で1.5倍可)
# 有名キーワード (+8)
# 影響力キーワード (+3/個, max +10)
# 個人的キーワードペナルティ (-15)
return min(100, max(40, score))
```

**問題点**:
| 問題 | 根拠 | 影響 |
|------|------|------|
| **テック偏重** | Top100中32%が科学・技術カテゴリ | 感動的エピソードが埋もれる |
| **感銘度無視** | キーワード一致のみで品質評価なし | 内容の良さが反映されない |
| **人物知名度無視** | celebrity_score_v2を使用せず | 無名人物が上位に来る可能性 |

**Top10の特徴**:
- ビル・ゲイツ、エイダ・ラヴレース、ティム・バーナーズ＝リー等IT系が過半
- ネルソン・マンデラ、キング牧師などの感動的エピソードが圏外

### 2.2 v2 (episode_fame_v2) の問題

**実装箇所**: `scripts/score/episode_fame_v2/scorer.py:1-150`

**計算式**:
```python
# 4コンポーネント + アンカーボーナス
total_score = (
    inspiration * 0.40 +   # 感銘度（キーワード or LLM）
    quality * 0.25 +       # 品質（LLM 7軸）
    historical * 0.20 +    # 歴史的インパクト
    person_fame * 0.15 +   # 人物知名度
    anchor_bonus           # 参考ランキング補正
)
```

**問題点**:
| 問題 | 根拠 | 影響 |
|------|------|------|
| **同一人物集中** | ジミー・カーター8件、マンデラ5件/Top100 | ランキングが1人に支配される |
| **偏差制御の未実装** | config.pyに定義あるがscorer.pyで未使用 | Top20/50/100の多様性ルール無効 |
| **スコアレンジ過大** | min=7.1, max=90.9 (83.8pt幅) | 微小差で大きく順位変動 |

**Top10の特徴**:
- マンデラ4件、マララ2件、キング牧師2件
- 「感銘重視」は達成だが、同一人物クラスタリングが致命的

### 2.3 v4 (episode_fame_score_v4) の問題

**実装箇所**: `scripts/score/episode_fame_v4/scorer.py:1-150`

**計算式**:
```python
# LLM重視 (45%) + キーワード (25%) + タイプ (15%) + 人物 (15%)
WEIGHTS = {
    "llm": 0.45,
    "keyword": 0.25,
    "type": 0.15,
    "person_fame": 0.15,
}
```

**問題点**:
| 問題 | 根拠 | 影響 |
|------|------|------|
| **壊滅的集中** | 葛飾北斎20件、黒澤明13件/Top100 | Top100の33%が2人に独占 |
| **LLM品質過重視** | 45%がLLM評価→高品質文が勝ちすぎ | エピソード内容より文章品質が支配 |
| **多様性ゼロ** | 57人/100件（最悪） | ランキングとして機能していない |

**Top10の特徴**:
- 葛飾北斎が9件/10件を独占
- 「富嶽三十六景」の同一エピソードが複数年齢で生成されTop独占

## 3. 失敗パターン分類

### パターンA: 同一エピソード重複
- 同じ業績が複数年齢で生成され、それぞれがTop入り
- 例: 北斎「富嶽三十六景」→ 70,71,74,75,77,78,79,81,82歳で生成

### パターンB: 人物知名度過重視
- 超有名人物のエピソードが全て上位に来る
- 例: ジミー・カーター（99歳まで生存）→ 多数のエピソード全てがTop入り

### パターンC: キーワード偏重
- 「世界初」「ノーベル賞」等のキーワードだけでスコア決定
- 内容の感動度・教育的価値が反映されない

### パターンD: カテゴリ偏り
- 科学・技術カテゴリが過剰に優遇される
- 芸術・スポーツ・社会活動のバランスが悪い

---

## 4. 改善に必要な方針（v2設計への入力）

### 必須要件
1. **同一人物制限**: Top20内1人max1件、Top50内max2件、Top100内max3件
2. **スコア正規化**: 外れ値（北斎問題）を抑制するlog/percentile正規化
3. **多シグナル統合**: PV・sitelinks・Google検索・LLM品質のバランス
4. **カテゴリバランス**: 特定カテゴリ偏重を抑制

### 検証観点
- Top100の人物多様性: 80人以上を目標
- カテゴリ分布: 最大カテゴリ30%以下
- アンカー集合との一致: 期待上位10件中8件以上がTop50入り
