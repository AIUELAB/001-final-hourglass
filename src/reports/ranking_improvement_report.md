## 1. 調査結果サマリー

### 1.1 現行の超総合スコア計算フロー

| 項目 | 内容 |
|------|------|
| 実装ファイル | `scripts/score/super_total_scorer.py` |
| 出力列 | `super_total_score`（0〜1,000,000） |
| バージョン | v1.2.0 |

**計算式**:
```
super_total_score = (
    0.30 × celebrity_norm +      # 人物有名度
    0.30 × episode_fame_norm +   # エピソード有名度
    0.20 × quality_norm +        # 7軸品質スコア
    0.20 × historical_norm       # 歴史的インパクト
) × (1 + achievement_boost) × penalty × 1,000,000
```

**ゲート**:
- 事実密度 < 6.0 → 除外
- 生成品質スコア < 6.0 → 除外

## 4. ギャップ分析レポート

### 4.1 指標比較

| 指標 | Claude | Gemini |

| NDCG@100 | 0.107 | 0.161 |
| 平均順位差 | +1,742 | +1,822 |

**解釈**: 現行ランキングと参照ランキングの乖離が非常に大きい

### 4.2 参照で高いが現行で低い（Undervalued）

| 人物名 | 参照順位 | 現行順位 | 順位差 |
|--------|----------|----------|--------|
| イチロー | 2位 | 1,111位 | +1,109 |
| 孫正義 | 3位 | 1,148位 | +1,145 |
| スティーブ・ジョブズ | 5位 | 446位 | +441 |
| マーク・ザッカーバーグ | 6位 | 776位 | +770 |
| カーネル・サンダース | 1位(Gemini) | 4,594位 | +4,593 |

### 4.3 現行で高いが参照に含まれない（Overvalued）

| 人物名 | 現行順位 | 特徴 |
|--------|----------|------|
| 大江健三郎 | 2位 | ノーベル文学賞 |
| 坂口志文 | 3位 | ノーベル賞関連 |
| カズオ・イシグロ | 4位 | ノーベル文学賞 |
| 湯川秀樹 | 5位 | ノーベル物理学賞 |

### 4.4 特徴差分析

| 特徴 | 参照に含まれる群 | 参照に含まれない群 | 差 |
|------|------------------|--------------------|----|
| celebrity_score_v2 | 高い（+56〜96） | 低い | 参照は「有名人」重視 |
| episode_fame_v6 | 低い（-5〜6） | 高い | 参照はEP有名度より人物有名度重視 |
| episode_importance | 低い（-52〜53） | 高い | **現行は「歴史的偉業」を重視しすぎ** |

### 4.5 根本原因の仮説

1. **episode_fame_v6がノーベル賞エピソードに高く出る傾向**
   - ノーベル賞受賞の事実はWikipediaで頻繁に言及される
   - 結果としてepisode_fame_v6が高くなる

2. **「典型的な日本人が読みたい」とは**
   - **知名度が高い人物**（大谷翔平、イチロー、孫正義等）
   - **共感できるストーリー**（起業、挑戦、逆境克服）
   - **意外性のあるエピソード**
   - ノーベル賞受賞者は「すごい」が「共感」しにくい

## 5. 改善案

### 5.1 推奨案（説明可能・安全）

**重み調整案 v2.0.0**:

```python
# 現行 v1.2.0
weight_celebrity = 0.30
weight_episode_fame = 0.30
weight_quality = 0.20
weight_historical = 0.20

# 推奨 v2.0.0
weight_celebrity = 0.55      # +25%: 人物有名度を重視
weight_episode_fame = 0.15   # -15%: EP有名度の影響を抑制
weight_quality = 0.30        # +10%: 品質を重視
weight_historical = 0.00     # -20%: 歴史的インパクトを無効化
achievement_boost_multiplier = 0.5  # 偉業ブーストを半減
```

**期待効果**:
- NDCG@100: 0.098 → 0.109（+11%）
- Overlap@100: 8.2% → 9.3%（+1.0pp）

**限界**:
- 参照で高順位の人物×年齢の組み合わせが現行CSVに高品質で存在しない
- 根本的改善には**エピソード追加**が必要

### 5.2 代替案A: 学習toランキング（Learning to Rank）

**概要**: 参照データを教師信号として、重みを機械学習で最適化

```
モデル: LightGBM Ranker / XGBoost Ranker
特徴: celebrity_score_v2, episode_fame_v6, 7軸スコア, etc.
目的関数: NDCG@100
```

| 項目 | 内容 |
|------|------|
| メリット | データから直接学習、複雑な関係も捕捉 |
| デメリット | ブラックボックス化、過学習リスク |
| 採用条件 | 教師データ200件以上、定期的な再学習 |

### 5.3 代替案B: エピソード追加施策

**参照に入るが現行で低い人物のエピソード強化**:

1. **優先追加対象**（参照Top10で現行1000位以下）:
   - イチロー（27歳）: マリナーズ移籍エピソード
   - 孫正義（24歳）: ソフトバンク創業エピソード
   - カーネル・サンダース（65歳）: KFC創業エピソード

2. **品質要件**:
   - 事実密度 ≥ 8.0
   - 意外性スコア ≥ 8.0
   - ストーリー品質 ≥ 8.0

## 8. 結論と次のステップ

### 8.1 現状の限界

重み調整だけでは改善幅が限定的（NDCG +11%、Overlap +1.0pp）。
根本原因は**参照で高順位の人物×年齢のエピソードが現行CSVに不足**していること。

### 8.2 推奨アクション

1. **短期（即時）**: v2.0.0設定を適用し、現行比+11%の改善を実現
2. **中期（1-2週間）**: 参照Top30で現行1000位以下の人物のエピソードを追加
3. **長期（1ヶ月）**: A/Bテストでユーザー行動データを収集し、Learning to Rank導入を検討
