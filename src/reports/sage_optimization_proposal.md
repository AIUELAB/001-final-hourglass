## 4. Smart Adaptive Generation Engine 設計案

### 4.1 段階的ゲート（早期棄却）

```
[候補選択]
    ↓
[Pre-LLM Gates] ← LLM不要のルールベースフィルタ
  ├─ 年齢境界チェック (birth_year, death_year)
  ├─ 同一年齢重複チェック (existing_episodes)
  ├─ クールダウンチェック (24h制限)
  ├─ 週次制限チェック (7日で5件まで)
  ├─ カテゴリクォータ (過剰カテゴリ抑制)
  └─ 候補スコア閾値 (priority < 0.3 除外) ← 新規
    ↓
[LLM Generation] ← ここで初めてLLM呼び出し
```

**実装箇所**: `scripts/sage/pre_generation_rules.py`

### 4.2 適応的生成

```python
class AdaptiveGenerator:
    """人物/失敗理由に応じた生成戦略切替"""

    def select_strategy(self, candidate, failure_history):
        # カテゴリ別プロンプト選択
        if candidate.category in ["政治", "歴史"]:
            template = "factual_heavy"
        elif candidate.category in ["芸能", "スポーツ"]:
            template = "narrative_focused"
        else:
            template = "balanced"

        # 失敗理由別の調整
        if "low_specificity" in failure_history:
            template += "_with_facts"  # 事実注入版
        if "prohibited_pattern" in failure_history:
            template += "_strict"  # 禁止表現強調版

        return template
```

**実装箇所**: 新規 `scripts/sage/adaptive_strategy.py`

### 4.3 キャッシュ・再利用

```
[キャッシュ層]
├─ PersonFactCache        # 人物の事実情報（Wikidata）
│   └─ TTL: 7日、差分更新
├─ FailurePatternCache    # 失敗パターンと改善テンプレ
│   └─ TTL: 30日
├─ EvaluationCache        # 評価結果（類似度>0.95）
│   └─ TTL: 永続
└─ PromptTemplateCache    # 高品質EPの構造パターン
    └─ 手動更新
```

**実装箇所**: 新規 `scripts/sage/cache/` ディレクトリ

### 4.4 モデル使い分け

```
[生成フェーズ]
├─ 1回目: claude-3-5-haiku (低コスト)
│   └─ composite_score >= 500 → 採用
├─ 2回目: claude-sonnet-4 (高品質)
│   └─ 1回目失敗時のみ
└─ 評価: claude-3-5-haiku
    └─ 評価タスクは軽量モデルで十分

[コスト比較]
- Haiku: $0.25/M in, $1.25/M out
- Sonnet: $3/M in, $15/M out
- 期待削減: 40-60%
```

**実装箇所**: `scripts/sage/config.py`, `llm_clients.py`

### 4.5 計測と自動最適化

```yaml
KPI定義:
  primary:
    - llm_calls_per_episode: 目標 < 1.3
    - tokens_per_episode: 目標 < 1500
    - acceptance_rate: 目標 > 90%

  secondary:
    - avg_super_total: 目標 > 400,000
    - retry_rate: 目標 < 20%
    - fallback_rate: 目標 < 10%

  diversity:
    - category_balance: Gini係数 < 0.3
    - age_distribution: 標準偏差 < 15

週次レポート:
  - KPI達成状況
  - コスト推移グラフ
  - 失敗理由内訳
  - 改善提案（自動生成）
```

**実装箇所**: 新規 `scripts/sage/kpi_tracker.py`

### 4.6 失敗理由別の最短修復ループ

```
[失敗理由] → [修復アクション]

low_specificity:
  → 事実注入プロンプト
  → Wikidata事実を自動追加
  → 成功率: 70%

prohibited_pattern:
  → パターン除去指示追加
  → 別角度から再生成
  → 成功率: 80%

low_factual_density:
  → 年号・数値強調プロンプト
  → 事実チェックリスト付与
  → 成功率: 75%

high_similarity:
  → 別の年齢/切り口で再生成
  → 成功率: 90%

fabrication_detected:
  → 即リジェクト（再生成しない）
  → 人物を候補から除外
```

**実装箇所**: `scripts/sage/quality/improvement.py` 拡張
