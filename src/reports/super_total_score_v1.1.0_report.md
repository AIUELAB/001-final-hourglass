## 技術的修正点

### 問題
`episode_importance_score`のスケールが不均一:
- 大谷翔平: 8.2
- ハービー・ハンコック: 159.7
- 阿部詩: 285.6

単純に`/100`で除算すると、低い値(8.2)が不当に不利になる。

### 解決
ロバスト正規化を適用:
```python
# 修正前
historical_norm = value / 100  # 不公平

# 修正後
historical_norm = self._robust_normalize(
    value,
    self.norm_params.importance_median,  # 7.9
    self.norm_params.importance_iqr,     # 1.0
)
```

シグモイド変換により、中央値付近の値が0.5、外れ値も0-1に収まる。
