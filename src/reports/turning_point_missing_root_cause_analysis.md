# 最重要転機エピソード欠落 - 根本原因分析

## 調査日: 2026-01-04

## 対象事例
- **人物**: ウラジーミル・プーチン (PA254CB0)
- **欠落エピソード**: 2000年 大統領初当選（47歳）
- **現状**: EP-EDDA23B9 として手動追加済み (source: TURNING_POINT_MANUAL)

## 根本原因

### 1. BIAS_CONTROL制限（最大の原因）

**ファイル**: `scripts/score/episode_fame_v6/scorer.py` (行298-335)
**設定**: `scripts/score/episode_fame_v6/config.py` (行312-316)

```python
BIAS_CONTROL = {
    20: 1,  # Top20内: 同一人物max 1件
    50: 2,  # Top50内: 同一人物max 2件
    100: 3, # Top100内: 同一人物max 3件
}
```

**問題**: 同一人物のエピソードがスコア順で選定され、上位N件のみが採用される。
最重要転機（大統領就任等）がスコア的に他のエピソードより低い場合、BIAS_CONTROL制限で押し出される。

### 2. 転機優先スロットがスコアリング段階で未使用

**ファイル**: `scripts/generate/generate_with_quality_gate.py` (行183)

```python
TURNING_POINT_EXTRA_SLOTS = 2  # 5件制限を超えて2件まで転機を許可
```

この設定は生成段階でのみ参照され、最終的なランキング選定（episode_fame_v6スコアリング）では使用されていない。

### 3. episode_typeがランキング選定に反映されない

**ファイル**: `scripts/calculate_episode_fame_v6.py`

- 生成時に `episode_type = "TURNING_POINT"` が設定される
- しかし、BIAS_CONTROL適用時にepisode_typeは考慮されない
- 結果: 転機エピソードも一般エピソードも同等に制限を受ける

## 欠落の具体的メカニズム（プーチンの例）

1. **生成段階**: 複数年齢でエピソード生成
   - 5歳（幼少期）
   - 13歳（柔道開始）
   - 44歳（FSB長官→大統領府副長官）
   - 47歳（大統領初当選）← 最重要転機
   - 53歳（ユコス社解体）
   - 59歳（大統領再出馬表明）

2. **スコアリング段階**:
   - 各エピソードにepisode_fame_v6スコアを算出
   - Tier1キーワード（大統領就任）へのボーナスは加算されている

3. **BIAS_CONTROL適用**:
   - 同一人物（PA254CB0）のエピソードを制限
   - 上位スコア順に1-3件のみ採用
   - 47歳「大統領初当選」がスコア的に他より低い場合 → 落選

4. **結果**: 最重要転機が自動パイプラインで選定されず、手動追加が必要になった

## 推奨改善方針

### 短期（即座に実装可能）
1. **BIAS_CONTROLでTier1キーワード含有エピソードを優先**
   - Tier1含有 → 制限を +1件増加
   - または、Tier1エピソードは制限対象外

### 中期
2. **バイアス制御を2段階化**
   - 第1段階: Tier1エピソードを先行採用（転機保護）
   - 第2段階: 残りにBIAS_CONTROL適用

3. **転機カバレッジ検証ゲートを追加**
   - 有名人物（fame_score上位N人）の転機エピソードが1件以上あることを検証
   - 0件の場合は警告/ブロック

### 長期
4. **監視ダッシュボード**
   - 上位人物の転機カバレッジ率を定期計測
   - 低下時にアラート

5. **回帰テスト**
   - 特定人物×重要イベントの組み合わせで欠落がないことを検証
