## 7. 技術詳細

### 評価プロンプト（v2.4.1）
- 厳格な採点基準を明示
- 9-10点は「歴史に残る極めて稀な事例」のみ
- 5-6点を標準的エピソードの中央値と定義

### スコア計算式
```
InspirationScore = Σ(axis_score × weight) × 10 + narrative_bonus

weights = {
  difficulty: 0.25,
  effort: 0.20,
  decision: 0.15,
  achievement: 0.25,
  social_impact: 0.15
}

narrative_bonus = min(5.0, narrative_depth × 0.5)
```
